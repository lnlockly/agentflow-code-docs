# Dependency Map

## TL;DR

Это **карта импортов бэкенда `agentflow-agents`** — открываешь в браузере и видишь, какая папка тянет какую, и какой файл от какого зависит. Две картинки: сначала крупный план на уровне папок (18 узлов — легко окинуть взглядом), потом полная карта всех 658 файлов. Граф собран локально через `dependency-cruiser` + `graphviz`; **код никуда не уходит**, картинки лежат прямо в этом сайте как обычные SVG.

Эта страница — для просмотра связей в браузере. Если нужен высокоуровневый «кто с кем общается» (контейнеры, потоки данных), смотри [C4 Architecture Map](/architecture/c4-overview); тут — механический import-граф из реального кода.

## Findings (architectural smells)

`dependency-cruiser` нашёл **140 циклических зависимостей** (circular imports) среди 658 модулей. Это реальные смеллы: цикл означает, что два-три файла нельзя загрузить независимо, и рефактор одного тянет остальные. Распределение по папкам (сколько раз файл папки участвует в цикле):

| Папка | Участий в циклах |
|---|---|
| `services` | 628 |
| `mcp-servers` | 387 |
| `routes` | 56 |
| `ui-templates` | 9 |
| `scripts` / `ai-router` | 2 каждая |

Два характерных примера:

- **Короткий, чинится барьерным файлом** — `ui-templates/index.ts` ↔ `ui-templates/telegram-mcp.ts` (и так же `self-mcp.ts`, `knowledge-mcp.ts`). Барреля `index.ts` ре-экспортит модуль, который импортит сам барель. Фикс: импортить конкретный файл, а не `./index`.
- **Длинный, через всю спину** — `services/projects.ts → mcp-servers/code-exec → … → services/runtime-supervisor → services/pool-worker → … → services/projects.ts`. Десяток файлов в одном кольце между `services/` и `mcp-servers/code-exec`. Это та самая ось `mcp-servers ↔ services` с 443+60 рёбрами — её стоит разрезать интерфейсом (порт), а не прямыми импортами.

Полный список циклов воспроизводится командой из раздела ниже (`--output-type err`).

## How it was generated (reproducible)

Граф собран из репозитория `agentflow-agents` (read-only, ничего не правилось). `agentflow-agents` использует NodeNext-резолюцию с `.js`-расширениями в импортах, поэтому нужен `enhancedResolveOptions`, иначе `.js` не мапятся на исходные `.ts` и граф выходит без рёбер.

Временный конфиг (`/tmp/dc-config.cjs`, **не** коммитится в `agentflow-agents`):

```js
module.exports = {
  forbidden: [
    { name: 'no-circular', severity: 'warn', from: {}, to: { circular: true } },
  ],
  options: {
    doNotFollow: { path: 'node_modules' },
    includeOnly: '^src',
    tsPreCompilationDeps: true,
    tsConfig: { fileName: 'tsconfig.json' },
    enhancedResolveOptions: {
      extensions: ['.ts', '.tsx', '.js', '.jsx', '.json'],
      mainFields: ['module', 'main', 'types', 'typings'],
      conditionNames: ['import', 'require', 'node', 'default', 'types'],
    },
  },
};
```

Команды (из корня `agentflow-agents`, без глобальной установки):

```bash
# 1. Full file-level graph → dot. -Gnewrank=true нужен, иначе dot
#    падает с "trouble in init_rank" на 140 циклах.
npx --yes dependency-cruiser@latest --config /tmp/dc-config.cjs \
  --output-type dot "src/**/*.ts" \
  | dot -Tsvg -Gnewrank=true \
  > ../agentflow-code-docs/public/dep-graph/dep-graph-full.svg

# 2. Collapsed top-level-folder graph → dot → SVG.
npx --yes dependency-cruiser@latest --config /tmp/dc-config.cjs \
  --collapse "^src/[^/]+" --output-type dot "src/**/*.ts" \
  | dot -Tsvg \
  > ../agentflow-code-docs/public/dep-graph/dep-graph-collapsed.svg

# 3. Cycle report (the Findings above).
npx --yes dependency-cruiser@latest --config /tmp/dc-config.cjs \
  --output-type err "src/**/*.ts"
```

Картинки самодостаточны: единственные `http://`-ссылки в SVG — это W3C XML namespace и DTD URI (стандартный SVG-бойлерплейт, не CDN, не грузятся в рантайме). `<script>`-тегов нет.

## Failure modes

| Symptom | Log signature for grep | Where to fix |
|---|---|---|
| `dependency-cruiser` cruises 0 dependencies | `0 modules, 0 dependencies cruised` | Pass a glob target `"src/**/*.ts"` (not a bare `src` dir) and `--no-config` or `--config` |
| Graph has nodes but no edges | edges count 0 in the `.dot` | NodeNext `.js` imports unresolved — add `enhancedResolveOptions.extensions` so `.js` maps to `.ts` |
| `dot` aborts rendering the full graph | `trouble in init_rank` | The 140 cycles break strict ranking — render with `dot -Gnewrank=true` |
| SVG renders as a force-directed hairball | n/a (visual) | Don't fall back to `sfdp`; `dot -Gnewrank=true` keeps the readable hierarchical clusters |
