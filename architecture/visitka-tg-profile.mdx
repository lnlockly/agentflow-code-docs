# Визитка (tg_profile_bundle)

## TL;DR

`tg_profile_bundle` boilerplate (id=18) builds an AI-powered Telegram profile page: scrapes the target's TG profile, scaffolds a landing, wires the design API, deploys landing + bot, and wires a booking flow. Triggered as a sub-project from diploma DAG (`tg_farm` kind, boilerplate id=31).

## Files

| Repo / path | Что делает |
|---|---|
| `agentflow-agents/src/services/graph-executor/handlers/tg-profile-bundle.ts` | All node handlers: `scrape_tg`, `deploy_landing`, `scaffold_bot`, `wire_designapi`, `deploy_bot`, `booking_flow` |
| `agentflow-agents/src/services/build-node-wrappers.ts` | `runBuildScrapeTgProfile`, `runBuildWireDesignapi` — delegates to coder agents |
| `agentflow-agents/src/services/runtime-supervisor.ts` | `deploy()` — called by `deploy_landing` and `deploy_bot` |

## DB tables / env / API surface

- Tables: `agent_boilerplates` (id=18 for tg_profile_bundle, id=31 for diploma/tg_farm)
- Nodes in boilerplate 18: `scrape_tg` → `deploy_landing` → `scaffold_bot` → `wire_designapi` → `deploy_bot` → `booking_flow`
