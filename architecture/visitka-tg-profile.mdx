# Визитка (tg_profile_bundle)

## TL;DR

`tg_profile_bundle` создаёт лендинг-визитку (Vite + React) + бот-ассистент (aiogram 3)
по любому @-хэндлу. Scaffold пишет файлы в `/workspace` на approve; coder-агент
полирует их. Кадди раздаёт `/workspace/dist/` через preview sidecar.

Часть библиотеки canonical templates — см. [runbooks/canonical-templates](/runbooks/canonical-templates). У других kinds (landing/spa/tg_bot/mini_app) теперь есть свои scaffolds той же формы.

## Data flow

```
approve
  → scaffoldTgProfileBundle()       — пишет frontend/ backend/ Procfile scripts/
  → autoCreateTelegramBot()          — назначает бот-токен в bot_token.txt
  → plan_started → task_claimed
  → runtime-supervisor.deploy(flag_gated)
      → detectRuntime() → type=mixed (Procfile)
      → launch web: bash scripts/build-profile.sh
                  && cd frontend && npm install && npm run build
                  && cd .. && cd dist && python3 -m http.server 8080
      → launch bot: python3 -u backend/bot.py
  → postDeployHealthCheck → repoint Caddy → preview_url live
  → audit_verdict → done
```

## Root-cause deep-dive (PR #222)

**Bug:** `INDEX_HTML` const in `tg-visitka-scaffold.ts` had:
```html
<link rel="stylesheet" href="/assets/index.css" />
<script type="module" src="/assets/index.js"></script>
```
These are pre-built output paths. Vite resolves entry modules from **source** paths,
not output paths. Build exited with:
```
Error: Failed to resolve /assets/index.js from /workspace/frontend/index.html
```
The `web:` process crashed → `/workspace/dist` never created → Caddy served placeholder
(200 OK) → preview probe passed → project marked `done`.

**Fix (PR #222):** Changed to `<script type="module" src="/src/main.tsx"></script>`.
Vite replaces this with the hashed output path during build. CSS `<link>` removed —
Vite injects it from the `import './app.css'` in main.tsx.
