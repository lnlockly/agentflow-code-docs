# Визитка (tg_profile_bundle)

## TL;DR

`tg_profile_bundle` создаёт лендинг-визитку (Vite + React) + бот-ассистент (aiogram 3)
по любому @-хэндлу. Scaffold пишет файлы в `/workspace` на approve; coder-агент
полирует их. Кадди раздаёт `/workspace/dist/` через preview sidecar.

Часть библиотеки canonical templates — см. [runbooks/canonical-templates](/runbooks/canonical-templates). У других kinds (landing/spa/tg_bot/mini_app) теперь есть свои scaffolds той же формы.

**Style variants (2026-05-14):** scaffold теперь печёт стиль в `profile.json.style` ∈ { `cyber`, `minimal`, `luxury`, `playful`, `dark-techno` } на основе brief + scraped bio/posts. App.tsx применяет `data-style={style}` — все 5 тем лежат в одном `app.css` через CSS custom properties. Coder pass — только полировка, scaffold-direct fill убил необходимость в slot rewrites (issue #622: 17-минутные билды).

## Data flow

```
approve
  → scaffoldTgProfileBundle({brief})
      → readScrapeSignals() — code-exec reads /workspace/scraped_*.json
      → selectVisitkaStyle({brief, about, postsText}) → 1 of 5 styles
      → injectVisitkaStyle(PROFILE_LOADER_PY, style) — bakes DEFAULT_STYLE
      → code-exec heredoc → frontend/ backend/ Procfile scripts/
  → autoCreateTelegramBot()          — назначает бот-токен в bot_token.txt
  → plan_started → task_claimed
  → runtime-supervisor.deploy(flag_gated)
      → detectRuntime() → type=mixed (Procfile)
      → launch web: bash scripts/build-profile.sh
                  → python3 backend/profile_loader.py
                       → profile.json {…, "style": "cyber"}
                  && cd frontend && npm install && npm run build
                  && cd .. && cd dist && python3 -m http.server 8080
      → App.tsx fetches profile.json → applies <main data-style={style}>
      → launch bot: python3 -u backend/bot.py
  → postDeployHealthCheck → repoint Caddy → preview_url live
  → audit_verdict → done
```

## Style selector

`selectVisitkaStyle({brief, about, postsText})` — pure, deterministic, side-effect-free.

| Style | Keywords (ASCII / Cyrillic) | Visual |
|---|---|---|
| `cyber` | crypto, web3, defi, nft, btc, eth, developer, coder, fullstack, ai battle / разработ, разраб, кодер | neon green on black + monospace + grid overlay |
| `luxury` | luxury, premium, jewel, gold, couture, concierge, atelier / элит, роскош, премиум, консьерж | burgundy + gold serif (Playfair) + italic |
| `playful` | kids, child, girl, cartoon, playful, cute, kawaii, lifestyle, fashion blogger / дет, весел, пастель, игрушк, мам | pastel gradients + rounded blobs + Quicksand |
| `dark-techno` | techno, rave, club, underground, industrial, drum & bass, edm, berghain, noir, brutalist | deep purple grid + electric pink gradient |
| `minimal` (fallback) | minimal, clean, swiss, aesthetic, gallery, portfolio, architect, designer / типографик, архитект | white-on-light, Inter 400, lots of whitespace |

Priority is **first-match-wins** in bucket order (cyber → luxury → playful → dark-techno → minimal). A brief saying "crypto trader" beats a scraped bio saying "luxury concierge".

Override во время отладки: `VISITKA_STYLE=cyber python3 backend/profile_loader.py` — env var trumps the baked DEFAULT_STYLE in `profile_loader.load()`.

## Root-cause deep-dive (PR #222)

**Bug:** `INDEX_HTML` const in `tg-visitka-scaffold.ts` had:
```html
<link rel="stylesheet" href="/assets/index.css" />
<script type="module" src="/assets/index.js"></script>
```
These are pre-built output paths. Vite resolves entry modules from **source** paths,
not output paths. Build exited with:
```
Error: Failed to resolve /assets/index.js from /workspace/frontend/index.html
```
The `web:` process crashed → `/workspace/dist` never created → Caddy served placeholder
(200 OK) → preview probe passed → project marked `done`.

**Fix (PR #222):** Changed to `<script type="module" src="/src/main.tsx"></script>`.
Vite replaces this with the hashed output path during build. CSS `<link>` removed —
Vite injects it from the `import './app.css'` in main.tsx.
