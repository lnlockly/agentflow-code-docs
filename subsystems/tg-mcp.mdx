# TG MCP (Telethon pool)

## TL;DR

Отдельный Python 3.12 сервис (FastMCP + Telethon) выполняет MTProto-операции над user-owned TG-аккаунтами. Sessions хранятся как Fernet-encrypted blob в SQLite (`accounts.session_blob`); per-account-id lock + LRU `max_size=32` — TelethonPool не может одновременно держать тысячи коннектов. Auth — JWT HS256 (issued агентом-агентов), exempt routes `/health`, `/`, `/sse/messages`, OPTIONS. Все TS-сервисы внутри agentflow-agents ходят через `${TG_MCP_URL}`.

## Data flow

```
Coder agent / Maestro / service в agentflow-agents
   ↓ MCP client POST ${TG_MCP_URL}/mcp { tool: "send_message", args: {...} }
   ↓ Authorization: Bearer <JWT HS256, sub=owner_user_id, secret=AUTH_JWT_SECRET>
MCPAuthMiddleware (server.py:29)
   ↓ verify JWT → set request.state.caller = Caller(owner_user_id=…)
   ↓ exempt: /health, /, /sse/messages, OPTIONS
FastMCP tool dispatch (_register_tools, server.py:105)
   ↓
TelethonPool.client(owner_user_id, phone)  — telethon_pool.py:57
   ↓ acquire per-account-id lock (no concurrent calls for same account)
   ↓ load Account from sqlite (storage.py)
   ↓ _decode_session (Fernet unwrap, crypto.py:12)
   ↓ TelegramClient(StringSession(...), api_id, api_hash) — connect/reuse
   ↓ run MTProto operation
   ↓ _persist_session (Fernet wrap) — save updated session
   ↓ release lock
   ↓ return tool result
```

## DB / env / API surface

**SQLite (`DB_PATH`):**
- `accounts` (`owner_user_id`, `phone`, `session_blob BLOB`, `status`, `auth_step`, `created_at`, `updated_at`). Unique (owner_user_id, phone).

**Env:**
- `TG_API_ID`, `TG_API_HASH` — Telegram developer credentials.
- `FERNET_KEY` — base64 32B key для wrap/unwrap session blob.
- `MCP_AUTH_SECRET` — старый X-MCP-Auth header secret (legacy fallback).
- `AUTH_JWT_SECRET` — shared с agentflow-agents (HS256).
- `AGENTFLOW_AGENTS_URL=http://agentflow-agents:4100` — куда тикает back-callback.
- `INTERNAL_API_SECRET` — for callbacks `/internal/tg-callbacks` в agentflow-agents.
- `SESSION_DIR` — на случай файловой Telethon-session (legacy).
- `MCP_HOST=127.0.0.1`, `MCP_PORT=4500` — bind.

**HTTP / MCP API:**
- `GET /health` — exempt, returns `{ok: true}`.
- `POST /mcp` — streamable HTTP transport (FastMCP streamable_app).
- `GET /sse` / `POST /sse/messages` — SSE transport (FastMCP sse_app, messages path exempt).
- 24 MCP tools — см. строки 105-469 server.py.

**Callbacks → agentflow-agents:**
- `POST /internal/tg-callbacks` (`agentflow-agents/src/routes/internal.ts:49`) — после получения нового сообщения через Telethon.

## Failure modes

| Симптом | Лог-строка для grep | Где починить |
|---|---|---|
| `401 invalid_token` от MCP | `mcp_auth_jwt_invalid` | `server.py:29` (MCPAuthMiddleware) |
| Session blob не расшифровался | `fernet_decrypt_failed` | `telethon_pool.py:39` (_decode_session) |
| Несколько параллельных вызовов на один аккаунт | `account_lock_timeout` | `telethon_pool.py:32` (per-account lock) |
| Pool переполнен | `telethon_pool_evict` (LRU eviction normal) | `telethon_pool.py:30` (max_size=32) |
| Phone code expired | `phone_code_expired` | `_register_tools` (auth tools, server.py:105) |
| Callback to agentflow-agents 500 | `tg_callback_send_failed` | `routes/internal.ts:49` |
