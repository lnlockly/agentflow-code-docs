# Research ingest

## TL;DR

Two HTTP endpoints on `agentflow-agents` let a research agent ingest external
sources into its Eliza `plugin-knowledge` store without the user copy-pasting
text. `POST /agents/:slug/knowledge/url` does server-side fetch + Mozilla
Readability → forwards extracted markdown via the existing knowledge data:
URL upload. `POST /agents/:slug/knowledge/youtube` runs the existing
`transcribe.py captions` asset in the user's project pod; Whisper is
opt-in (`fallback=whisper`) and runs async with a job id.

Both endpoints charge via `debitCredits()` from `services/stars-billing.ts`
and refund on any downstream failure.

## Data flow

```
[User] paste URL or YT link in /research sidebar
        │
        ▼
POST /agents/:slug/knowledge/{url|youtube}
        │
        ├─ validate input (private-IP / YT host filter)
        ├─ debitCredits(5¢)
        │
URL ────┼─ fetch (15s timeout, 5MB cap, redirect:follow)
        │     │
        │     ▼
        │  readability(jsdom) → title + markdown
        │     │
        │     ▼
        │  proxy POST to Eliza /api/agents/<id>/plugins/documents
        │  (data:text/plain;base64 fileUrl)
        │
YT  ────┼─ callCodeExecTool('exec', { project, command:
        │     'python3 /workspace/assets/youtube-transcriber/transcribe.py captions --url X' })
        │     │
        │     ├─ ok → format with [hh:mm:ss] → forward as data: URL
        │     │
        │     └─ no captions
        │            ├─ fallback=captions_only (DEFAULT) → 422 with hint
        │            └─ fallback=whisper → debit 15¢, spawn `transcribe.py full`
        │                                  via nohup, return { job_id, status:processing }
        │
        ▼
On any downstream non-2xx → refundCredits(userId, cents, 'refund_knowledge_ingest')
```

## DB / Env / API

- **Tables:** none new; piggybacks on Eliza `plugin-knowledge` documents/fragments
  and `user_credits` for billing. Refund reason recorded via `console.info`
  log line (audit log table can land later if compliance asks).
- **Env:**
  - `RESEARCH_DEFAULT_WORKSPACE` — optional project pod name used for the
    YouTube transcribe runner. When unset, falls back to the user's most
    recent `projects.workspace_project_name`.
  - `ELIZA_URL`, `ELIZA_API_KEY` (existing) — knowledge proxy target.
- **Routes:**
  - `POST /agents/:slug/knowledge/url` — body `{ url, title? }`.
  - `POST /agents/:slug/knowledge/youtube` — body `{ url, fallback?: 'captions_only' | 'whisper' }`.
- **MCP tools:** `code-exec.exec` (transcribe.py runner inside the project pod).
- **Pricing constants:** `URL_INGEST_COST_CENTS = 5`, `CAPTIONS_INGEST_COST_CENTS = 5`,
  `WHISPER_BASE_COST_CENTS = 15`, `WHISPER_PER_MIN_OVER_10_CENTS = 2`.

## Failure modes

| Symptom | Log signature for grep | Where to fix |
|---|---|---|
| URL ingest 400 with `invalid_url` | client-side validation error | `services/research-ingest.ts:24` (`validatePublicHttpUrl`) |
| URL ingest 400 with `private_host_blocked` | user paste an RFC1918 / loopback URL | expected — block intended |
| URL ingest 502 `fetch_failed` | external host returned non-2xx | `routes/knowledge.ts:284` — refund posted, surface upstream status |
| URL ingest 413 `response_too_large` | body exceeded `URL_FETCH_MAX_BYTES` (5MB) | `routes/knowledge.ts:307` — bump cap if a legitimate site needs more |
| URL ingest 422 `no_article_content` | readability returned nothing | `services/research-ingest.ts:91` — page is a SPA shell, manual paste needed |
| YouTube 400 `not_a_youtube_url` | URL host not in `YT_HOSTS` | `services/research-ingest.ts:115` |
| YouTube 409 `no_workspace` | user has no project with `workspace_project_name` | create a project or set `RESEARCH_DEFAULT_WORKSPACE` env |
| YouTube 422 `no_captions` | video lacks captions and fallback not requested | client opts in via `fallback: 'whisper'` |
| Refund log line on 4xx/5xx | `[stars-billing] refundCredits user=… reason=refund_knowledge_ingest` | `services/stars-billing.ts:418` |
| jsdom build error about undici-types | post-`npm i @types/jsdom` | local shim at `src/types/jsdom.d.ts` — do NOT install `@types/jsdom` |
