# Account groups (farms)

## TL;DR
An `account_groups` row is a user-owned set of connected accounts — a "farm":
`name` («Прогрев», «Поддержка») + `account_refs[]` of platform-native refs
(`telegram:42`). It backs the Пульт group pills (Все / Прогрев / Поддержка)
and gives a single ref-set for future bulk-command targeting through the
[approval queue](/subsystems/approval-queue). The table is platform-agnostic —
each ref carries its own `platform:` prefix, so there is **no per-platform
column or branch**.

## Data flow
```
Пульт group pills            bulk-command targeting (future)
        |                              |
   GET /me/account-groups        resolveGroupRefs(userId, groupId)
        |                              |  -> account_refs[]
  listGroups(userId) ------------------+     fans out over the
        |                                     approval queue
        v
  account_groups (owner-scoped by user_id)
  POST   -> createGroup
  PATCH  -> renameGroup | setMembers | updateMembers(add/remove)
  DELETE -> deleteGroup
```

PATCH body slots apply in order: `name` (rename) -> `account_refs` (replace
whole membership) -> `add`/`remove` (incremental delta). Any subset is allowed;
none recognised -> `400 nothing_to_update`.

## DB / Env / API
- Tables: `account_groups (id, user_id, name, account_refs text[], created_at, updated_at)`,
  index `idx_account_groups_user (user_id)`.
- Env: none new.
- Routes (all `requireSession`, owner = `session.sub`):
  - `GET    /me/account-groups` -> `{ ok, count, groups: AccountGroup[] }`
  - `POST   /me/account-groups { name, account_refs }` -> `201 { ok, group }`
  - `PATCH  /me/account-groups/:id { name?, account_refs?, add?, remove? }` -> `200 { ok, group }`
  - `DELETE /me/account-groups/:id` -> `200 { ok, deleted: true }`
- MCP tools: none (data layer only).

## Failure modes
| Symptom | Log signature for grep | Where to fix |
|---|---|---|
| Create rejected, empty name | route returns `name_required` | `src/account-groups/groups.ts:120` |
| Create/replace rejected, refs not an array | route returns `account_refs_invalid` | `src/account-groups/groups.ts:125` |
| PATCH/DELETE on a group you don't own -> 404 | route returns `not_found` | owner-scope `WHERE ... user_id = ${userId}` in `groups.ts` |
| PATCH with no known field -> 400 | route returns `nothing_to_update` | `src/routes/me-account-groups.ts:120` |
