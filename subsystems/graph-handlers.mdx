# Graph executor — node handlers

## TL;DR

The walker resolves each `WorkflowNode.id` to a typed handler via
`defaultRegistry.resolve(kind)`. 50+ unique node ids ship across 16
seeded boilerplates (5 originals + diploma composite + 6 TG-template
extras from PR #196); each has a handler under
`src/services/graph-executor/handlers/<group>.ts`. Deterministic work
(deploy, scrape, smoke-test, request_token, setup_bot, link_account)
wraps an existing service in ≤20 LOC. Generative work (pick_theme,
scaffold_*, *_flow) goes to a per-node coder-delegate with a tight
`OUTPUT_EXPECTED` envelope so the walker can validate the result.

The registry also resolves `kind:variant` suffixes (e.g.
`tg.send_text:deliver`) to the base handler, so the diploma DAG can
label per-edge variants without duplicate registrations.

Contract: [`architecture/graph-executor.mdx`](/architecture/graph-executor).

## Soft-gate, sanitizer, idempotency-on-resume

Three cross-cutting concerns landed in May 2026 (PRs #519 + #522 against
SPA + landing + mini-app + tg-bot handlers). They sit between the coder
turn and the post-coder gate.

### Soft-gate (`makeCoderHandler({ softGate: true })`)

`handlers/spa.ts:73-167` factory accepts `{ softGate: true }`. When the
coder produces no writes (`coder_did_nothing`) OR misses some `expects`
paths (`missing_expected_files`), the handler downgrades the failure to
a warning event (`<kind>_coder_did_nothing_soft` /
`<kind>_missing_expected_files_soft`) and returns
`{files_written: [], reply: '', delegated_to: slug}`. The graph
continues to the next edge.

Currently only `multi_tenant` runs in soft mode
(`handlers/spa.ts:244-259`) — multi-tenant Orgs are opt-in SaaS plumbing;
single-user briefs like "manage MY subscriptions" should still ship
admin_panel + deploy without the coder being forced to fabricate an
unused `org_context.guard.ts`. All other SPA nodes (`scaffold_nest`,
`scaffold_prisma`, `jwt_auth`, `billing_stripe`) stay hard-gate.

### JSX sanitizer for `App.tsx`

`spa-frontend-prefill.ts:920-922` exports
`sanitizeBrokenJsxEscapes(body)`. Targeted regex
`/\{\\"([^"\\]*)\\"\}/g → {"$1"}` heals the `{\"text\"}` artifact some
coders (notably haiku-4-5) emit when "polishing" prefilled JSX. They
re-serialize an already-correct `{"Главная"}` JSX expression container
through `JSON.stringify` a second time, planting literal `\` + `"`
bytes that esbuild rejects:

```
ERROR: Syntax error '"'
  <Link to="/">{\"Главная\"}</Link>
                 ^
```

`sanitizeSpaAppTsx(ctx)` (line 929) wraps it as a post-coder safety
net — read `App.tsx`, run sanitizer, `write_file` back via
`applyScaffoldInPod` only if the regex matched. Called from
`admin_panel` handler (`handlers/spa.ts:404-421`) after the coder
declares done, before deploy. Idempotent: clean files are not rewritten.

### Idempotency on `graph_executor_resumed`

`coder-output.ts:159-194` exports
`expectsAlreadySatisfied(exec, expects, sentinels?)`. For each entry in
the post-coder `expects[]` (with `||` alternatives), builds one shell
line:

```sh
{ [ -s 'path' ] && ! grep -qE 'BrandX|Acme Inc|SLOT:brief|{{SLOT:|<!-- SLOT:' 'path' 2>/dev/null; } \
  && echo OK:path \
  || echo FAIL:path
```

Returns `true` only when ALL entries print `OK:`. On exec failure
returns `false` — never a false positive that would skip a missing
file.

Wired into every coder-handler entry point:

| Handler | Run line |
|---|---|
| `handlers/spa.ts` `makeCoderHandler.run` | scaffold_nest, scaffold_prisma, jwt_auth, billing_stripe, multi_tenant |
| `handlers/spa.ts` `adminPanelHandler.run` | admin_panel (uses `ADMIN_PANEL_EXPECTS`) |
| `handlers/landing.ts` `makeCoderLandingHandler.run` | render_landing |
| `handlers/mini-app.ts` `makeCoderHandler.run` | scaffold_vite, tg_webapp_init |
| `handlers/mini-app.ts` `makeRoutesHandler.run` | routes (mini_app) |
| `handlers/tg-bot.ts` `scaffoldAiogramHandler.run` | scaffold_aiogram (`SCAFFOLD_AIOGRAM_EXPECTS` = `backend/bot.py`, `backend/requirements.txt`, `Procfile`) |

On hit the handler emits `node_skipped_idempotent` (event kind, payload
`{node_kind, delegated_to, reason: 'expects_already_satisfied',
expects}`) and returns
`{files_written: [], reply: '', delegated_to: slug}`. Downstream nodes
read the `expects` paths directly, so an empty `files_written` does not
break them.

Spec:
[`docs/specs/2026-05-19-coder-idempotency-on-resume.md`](https://github.com/lnlockly/agentflow-agents/blob/main/docs/specs/2026-05-19-coder-idempotency-on-resume.md).
