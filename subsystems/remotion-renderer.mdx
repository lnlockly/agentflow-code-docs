# Remotion renderer

## TL;DR

Standalone HTTP service (`agentflow-remotion-runner`, port 4200) that bundles
a Remotion entry once at first request, then renders any registered
composition by id with caller-supplied props. The MP4 is uploaded to MinIO
under `remotion/<composition_id>/<uuid>.mp4` and the public URL is returned to
the caller. PR-1 ships the runner pod, Dockerfile, k8s manifest, GHA build,
and one built-in composition (`simple-card`). PR-2 ships the
`@agentflow-video` MCP server with one tool `remotion.render` that POSTs to
this Service and surfaces the runner envelope to the LLM (5-minute fetch
timeout, owner-pinned mount). PR-3 will add the `remotion-video-operator`
preset that uses the tool.

## Data flow

```
agentflow-agents pod  ──POST /render──►  agentflow-remotion-runner pod
   (PR-2 MCP tool)            (Hono :4200)
                                  │
                                  ├─► getBundle()           (first request only, then cached)
                                  │     └─► @remotion/bundler → /tmp/remotion-bundle
                                  │
                                  ├─► selectComposition()   (resolves composition_id + merges props)
                                  │
                                  ├─► renderMedia()         (chromium → mp4 → /tmp/out-<uuid>.mp4)
                                  │
                                  └─► putObject()           (SigV4 PUT → minio:9000)
                                        └─► remotion/<composition_id>/<uuid>.mp4
                                  ◄── { ok, mp4_url, duration_sec, size_bytes }
```

## DB / Env / API

- **Tables:** none. Renderer is stateless.
- **Env (runner pod):**
  - `PORT` (default 4200)
  - `MINIO_ENDPOINT` (default `http://minio:9000`)
  - `MINIO_BUCKET` (default `agentflow-files`)
  - `MINIO_REGION` (default `us-east-1`)
  - `MINIO_ACCESS_KEY`, `MINIO_SECRET_KEY` (from `minio-creds` Secret)
  - `MINIO_PUBLIC_URL` (optional; falls back to in-cluster endpoint)
  - `REMOTION_CONCURRENCY` (default 2; match CPU limit)
  - `REMOTION_BUNDLE_CACHE` (default `/tmp/remotion-bundle`)
  - `REMOTION_ENTRY` (default `/app/src/index.ts`)
  - `REMOTION_CHROME_EXECUTABLE` (default `/usr/bin/chromium`)
- **Env (agents pod, PR-2):** `REMOTION_RUNNER_URL` (default in-cluster: `http://agentflow-remotion-runner:4200`). Empty value → tool returns `remotion_runner_not_configured`.
- **Routes (runner pod):**
  - `GET  /health` → `{ok:true, service:'remotion-runner'}`
  - `POST /render` → `{ok, mp4_url, composition_id, duration_sec, size_bytes, render_ms}` or `{ok:false, error, details?}`
- **Routes (agents pod):**
  - `POST /internal/mcp/video/?token=<INTERNAL_API_SECRET>&owner=<uid>` — JSON-RPC streamable-http MCP. `initialize`, `tools/list`, `tools/call`. Owner-pinned.
- **MCP tools (PR-2 shipped):**
  - `remotion.render({ composition_id, props?, fps?, duration_frames? })` — agentflow-agents proxies the POST to the runner Service and returns the runner envelope unchanged.

### MCP tool call shape

Wire-level JSON-RPC `tools/call`:

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "remotion.render",
    "arguments": {
      "composition_id": "simple-card",
      "props": { "title": "Hello", "subtitle": "World", "bgColor": "#000" }
    }
  }
}
```

Response (`result.content[0].text` is the JSON-encoded runner envelope):

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "isError": false,
    "content": [
      {
        "type": "text",
        "text": "{\"ok\":true,\"mp4_url\":\"https://files.proj.agentflow.website/remotion/simple-card/...mp4\",\"composition_id\":\"simple-card\",\"duration_sec\":30,\"size_bytes\":1234567,\"render_ms\":42000}"
      }
    ]
  }
}
```

### Request schema

```ts
{
  composition_id: string,         // required, e.g. "simple-card"
  props?: Record<string, unknown>, // forwarded to the composition
  fps?: number,                    // override registered fps (1..120)
  duration_frames?: number,        // override registered duration (1..7200)
  template_url?: string,           // reserved — PR-1 returns 400 if set
}
```

## Failure modes

| Symptom | Log / response signature for grep | Where to fix |
|---|---|---|
| Unknown composition id | response `{ok:false, error:"composition_not_found"}` | Add composition in `remotion-runner/src/Root.tsx`. |
| Render crash / prop type mismatch | response `{ok:false, error:"render_failed", details:"..."}` | Caller fix props; if Chromium crash, bump pod memory in `k8s/remotion-runner.yaml`. |
| Missing MinIO creds | response `{ok:false, error:"minio_credentials_missing"}` | Ensure `minio-creds` Secret projected into the pod env. |
| MinIO PUT failed | response `{ok:false, error:"minio_put_failed", details:"minio_put_failed: <code> ..."}` | Check bucket exists, policy, quota. |
| `template_url` rejected | response `{ok:false, error:"template_url_not_supported"}` | Use built-in `composition_id` until PR-2/3 wires arbitrary bundles. |
| Bundle stuck after tmpfs full | `[remotion-runner] listening` but `/render` hangs on bundle step | Pod restart clears it; bump `ephemeral-storage` limit in manifest. |
| Agents pod env missing runner URL | MCP tool returns `{ok:false, error:"remotion_runner_not_configured"}` (no HTTP attempted) | Set `REMOTION_RUNNER_URL` on `deploy/agentflow-agents` (k8s/agentflow-agents.yaml). |
| Runner pod down / Service unreachable | MCP tool returns `{ok:false, error:"remotion_runner_unreachable", details:"..."}` | `kubectl -n franchise-factory get pods -l app=agentflow-remotion-runner`; check restart count / OOMKilled. |
| Render >5 min | MCP tool returns `{ok:false, error:"remotion_runner_timeout"}` (AbortSignal.timeout fires) | Either shorten composition `duration_frames` or split into smaller renders. |
| Runner replies non-json | MCP tool returns `{ok:false, error:"remotion_runner_bad_response", details:"..."}` | Renderer regression — check pod logs for stack trace. |
