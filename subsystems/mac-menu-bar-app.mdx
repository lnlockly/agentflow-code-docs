# Mac menu-bar app

## TL;DR

Native SwiftUI status-bar app (macOS 13+) that polls the local agentflow
daemon socket every 10s and the cloud REST API every 30s. Ships inside the
`agentflow-computer-mcp` repo at `macapp/`. Bundle size ~420 KB.

## Data flow

```
        ┌──────────────────────────┐
        │   AgentFlow.app (menu)   │
        └────────────┬─────────────┘
                     │
        ┌────────────┼────────────────────┐
        ▼            ▼                    ▼
  10s socket     30s REST            Process spawn
        │            │                    │
        ▼            ▼                    ▼
  /tmp/agent…    agentflow.website     agentflow daemon
   flow.sock      /_agents/*            start | stop
   (local         /me/autonomous/
    daemon)        {goals,budget}
```

## DB / Env / API

- No DB. State lives only in `AppState` in-memory.
- Reads `~/.agentflow/auth.json` (written by Python CLI `agentflow login`).
- Calls REST `https://agentflow.website/_agents/me/autonomous/{goals,budget}`
  with `x-api-key` header.
- Calls UNIX socket `/tmp/agentflow.sock` with line-JSON
  `{"method":"list"}` → `{"ok":true,"result":[…]}`.

## Failure modes

| Symptom | Log signature for grep | Where to fix |
|---|---|---|
| Red dot, "Демон не запущен" | `SocketError.unavailable` from `SocketClient.call` | start daemon via menu "Запустить демон" button or `agentflow daemon start` |
| Cloud sections empty, "не авторизован" | `RestError.notAuthenticated` from `RestClient.get` | `agentflow login` to write `~/.agentflow/auth.json` |
| Cloud sections show 401 errors | `RestError.http(401, …)` | api_key in auth.json expired; re-run `agentflow login` |
| Gatekeeper refuses first launch | macOS "cannot verify developer" dialog | right-click .app → Open until codesign #77 ships |
| No menu-bar icon after launch | `LSUIElement` missing from Info.plist | check `Sources/AgentFlow/Resources/Info.plist:14` |
| Bundle > 5 MB | CI step `Verify bundle size <= 5 MB` fails | inspect what was added; SwiftUI dynamically links stdlib so binary should stay `< 1 MB` |
