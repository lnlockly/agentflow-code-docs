# Cloud IDE

## TL;DR
A browser VS Code (`code-server`) runs in a cluster pod at
`ide.agentflow.website`, with Claude Code pre-installed and a persistent
`/home/coder/workspace` volume — so development moves off the weak owner Mac into
the cloud. It is surfaced as a [JSON app](/subsystems/json-app-manifests)
(`app-manifests/cloud-ide.json`) with an `embed` panel pointing at the editor.
The k8s manifests live under `k8s/cloud-ide/`. The editor password is an
out-of-band Secret (`cloud-ide-auth`) — the Deployment maps the Secret key into
the `PASSWORD` env, and a missing Secret/key is the classic boot failure.

| `agentflow-agents/k8s/cloud-ide/SETUP.md:25` | Step 1: create the `cloud-ide-auth` Secret FIRST |

## Data flow
```
app-manifests/cloud-ide.json  → /apps/cloud-ide (embed panel)
                                   → iframe https://ide.agentflow.website
ingress ide.agentflow.website (TLS cloud-ide-tls)
   → code-server Deployment (codercom/code-server)
       env PASSWORD ← secretKeyRef cloud-ide-auth.password
       PATH/NPM_CONFIG_PREFIX → npm-global Claude Code on terminal PATH
       /home/coder/workspace ← PVC (persistent)
```

## DB / Env / API
- Tables: none.
- Env (pod): `PASSWORD` (from Secret `cloud-ide-auth` key `password`), `PATH` + `NPM_CONFIG_PREFIX` (npm-global Claude Code on PATH).
- Secret: `cloud-ide-auth` — created out of band (`kubectl … create secret generic cloud-ide-auth --from-literal=password=…`), NOT in git.
- Host: `ide.agentflow.website` (TLS via cert-manager, secret `cloud-ide-tls`).
- Manifest `uses.mcp_tools`: `["agentflow"]`.

## Failure modes
| Symptom | Log signature for grep | Where to fix |
|---|---|---|
| Pod stuck, container won't start | pod status `CreateContainerConfigError` | Secret `cloud-ide-auth` (or key `password`) missing — create it first, `agentflow-agents/k8s/cloud-ide/SETUP.md:25` |
| Editor prompts but rejects password | wrong key in `cloud-ide-auth` | `secretKeyRef … key: password`, `agentflow-agents/k8s/cloud-ide/10-deployment.yaml:93` |
| `kubectl apply -k` re-creates a placeholder secret | example secret leaks in | it is intentionally excluded from kustomization (`agentflow-agents/k8s/cloud-ide/kustomization.yaml:6`) |
| TLS not issued | host/cert mismatch | `agentflow-agents/k8s/cloud-ide/20-ingress.yaml:27` |
