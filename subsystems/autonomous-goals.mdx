# Autonomous Goals (Phase 0)

## TL;DR
A two-store goal engine. The desktop daemon keeps an authoritative local SQLite (`~/.agentflow/autonomous.db`) wired to a CLI, while `agentflow-agents` mirrors the same shape in Postgres and runs a UTC-scheduled wake/reflect worker that drops one task per goal into `device_tasks` for the user's primary device. The cabinet UI reads the Postgres copy through `/me/autonomous/*` and renders inside the device detail page (`DeviceAutonomousPanel`), not as a standalone route.

## DB / Env / API

- **SQLite (desktop)** — `~/.agentflow/autonomous.db`, 7 tables (see `schema.py:19`).
- **Postgres (server)** — 6 mirror tables under `autonomous_*` (no `sub_agents` mirror in Phase 0).
- **Env**:
  - `AUTONOMOUS_WAKE_HOUR_UTC` (server, optional, integer 0-23, default `4`)
  - `AF_UPDATE_INTERVAL_MIN` — orthogonal, used by the desktop self-updater
  - desktop reads `api_key` + `device_id` from `~/.agentflow/auth.json`
- **Routes** (auth: `requireSession` — cookie / API key / bearer):
  - `GET    /me/autonomous/goals`
  - `POST   /me/autonomous/goals` → 201 / 400 `invalid_body`
  - `GET    /me/autonomous/goals/:id` → 200 / 404 `not_found`
  - `PATCH  /me/autonomous/goals/:id`
  - `DELETE /me/autonomous/goals/:id`
  - `POST   /me/autonomous/goals/:id/decompose` → 202 / 502 `llm_call_failed` / 502 `no_milestones`
  - `POST   /me/autonomous/goals/:id/plan_today` (body `{device_id?}`) → 202 `{plan, dispatched_task_id}` / 502 `llm_call_failed`
  - `POST   /me/autonomous/goals/:id/pause`
  - `POST   /me/autonomous/goals/:id/resume` → 404 `not_found_or_not_paused`
  - `GET    /me/autonomous/budget`
- **CLI entry**: `python -m agentflow_computer_mcp.autonomous.cli {init|goal|plan|today|reflect|status}`

## Failure modes

| Symptom | Log signature for grep | Where to fix |
|---|---|---|
| Wake worker plans for a user with no active milestone | `wake_skipped_no_milestone` | `agentflow-agents/src/services/autonomous-worker.ts:187` — expected; surface as empty state in cabinet |
| Wake worker can't dispatch because user has no device | `wake_dispatched_skipped_no_device` | `agentflow-agents/src/services/autonomous-worker.ts:218` — user must link a device via cabinet |
| Single goal blows up the wake pass | `wake_goal_failed` | `agentflow-agents/src/services/autonomous-worker.ts:242` — inspect `err` field; loop continues for remaining goals |
| End-of-day reflection silently fails | `reflection_failed` | `agentflow-agents/src/services/autonomous-worker.ts:349` — LLM call or `JSON.parse` exception; row stays `reflection IS NULL` for re-attempt next tick |
| Whole tick crashed (cron-style) | `autonomous_tick_failed` | `agentflow-agents/src/services/autonomous-worker.ts:397` — the loop survives; check error text |
| `/me/autonomous/goals/:id/decompose` returns 502 | none (synchronous response) | response `{error: 'llm_call_failed'\|'no_milestones'}` — LLM call rejected JSON; check `ai-router` health |
| Desktop CLI `plan --decompose` exits 2 with no LLM call | `[autonomous] no api_key in ~/.agentflow/auth.json` | `agentflow-computer-mcp/src/agentflow_computer_mcp/autonomous/cli.py:49` — re-run install flow to write `auth.json` |
| Daemon `wake_cycle.run_forever` keeps logging tick failures | `wake_cycle tick failed:` | `agentflow-computer-mcp/src/agentflow_computer_mcp/autonomous/wake_cycle.py:272` — exception in `wake()` or `sleep_reflect()`; loop continues so the daemon never dies |
| Daemon failed to dispatch a planned task | error field `http <code>` returned from `dispatch_task_to_device` | `agentflow-computer-mcp/src/agentflow_computer_mcp/autonomous/wake_cycle.py:97` — 4xx means API key or device ownership; 5xx means agentflow-agents pod issue |
| Reflection LLM emitted prose, not JSON | `reflection_failed` AND row has non-null `reflection` text but `score IS NULL` | server-side fallback at `autonomous-worker.ts:336` stores raw text; the next reflection pass re-runs because score gate is independent |
| Budget alert never fires though spend > cap | none — `alert_if_over` returns `{triggered:true, dispatched:false, error:"no device_id/api_key wired"}` | `agentflow-computer-mcp/src/agentflow_computer_mcp/autonomous/budget.py:139` — daemon was started without `auth.json`; rerun installer |
| Goals show 0 milestones in cabinet though decompose succeeded | none | check `autonomous_milestones.user_id` matches caller — `persistMilestones` writes per-user, cross-user reads are blocked by the `WHERE user_id =` clause |
| Goal card renders `NaN / NaN ступенек` or bare `target_value` without unit | none — pure UI; reproduces on any fresh goal where `milestone_count`/`completed_count` are null and `target_metric` is empty | `agentflow-landing/src/components/devices/DeviceAutonomousPanel.tsx` uses `deriveMilestoneProgress` + `formatTargetValue` from `agentflow-landing/src/lib/autonomousGoalFormat.ts` — null counts collapse to 0 with «Декомпозиция готовится…»; USD/RUB/EUR/% get unit suffixes; empty metric hides the «метрика:» row |
