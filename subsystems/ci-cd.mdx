# CI/CD

## TL;DR
Two repos, two pipelines each:

- `agentflow-agents` — `pr-check.yml` runs `typecheck | build | test` in parallel on every PR (self-hosted runner). `deploy.yml` builds the GHCR image and rolls k3s on push to `main`.
- `agentflow-landing` — `e2e.yml` runs a Playwright smoke against `agentflow.website` on every PR; `deploy.yml` builds + rolls on push to `main`.

Branch protection on `agentflow-agents/main` requires `typecheck`, `build`, `test` status checks. Apply via `scripts/setup-branch-protection.sh`.

## Data flow

### agentflow-agents PR-check
```
developer git push <feature>
   ▼
GitHub PR ─────► pr-check.yml
                   ├── typecheck   (npm run typecheck = tsc --noEmit)
                   ├── build       (npm run build, uploads dist/ artifact 5d)
                   └── test        (npm test = node --test tests/**/*.test.ts; self-skips when absent)
                                  ▼
                                PASS → eligible for squash-merge
                                FAIL → branch protection blocks merge
```

### agentflow-landing E2E
```
PR opened
  → GH Actions e2e-smoke job (ubuntu-latest, 15min timeout)
     → npm ci → npx playwright install chromium → npm run e2e:smoke
        → goto agentflow.website/login → /cabinet → /cabinet/devices
        → click "Автономно" tab → POST autonomous/goals → assertNoNaN(page)
     → on failure: upload playwright-report/ + test-results/ artifacts
```

## DB / Env / API

### agentflow-agents
- No env required for `pr-check.yml` (runs without secrets).
- `deploy.yml` reads `GITHUB_TOKEN`, `KUBECONFIG`, registry creds (configured at runner level).
- Required status checks on `main`: `typecheck`, `build`, `test`.

### agentflow-landing
- Env (CI):
  - `E2E_BASE_URL` — defaults `https://agentflow.website`.
  - `E2E_OWNER_EMAIL` / `E2E_OWNER_PASSWORD` — GH secret. Falls back to
    `avsee4@agentflow.website` / brief-provided password.
  - `CI=true` — enables `[github]` reporter + `retries: 1`.
- Routes hit by the smoke:
  - `POST /login` (frontend form post).
  - `GET /cabinet/devices`.
  - `POST /me/devices/:device_id/autonomous/goals` — return must be < 300.
- Cleanup: goals named `[e2e] smoke <ts>` so owner can filter.

## Failure modes

### agentflow-agents PR-check
| Symptom | Log signature for grep | Where to fix |
|---|---|---|
| PR merged despite red CI | branch protection missing status checks | run `scripts/setup-branch-protection.sh` |
| typecheck job red | `error TS2322` (or any `error TS`) in workflow log | fix the type error in the PR |
| build job red | `error TS` or `tsc` non-zero exit | local repro `npm run build` |
| test job skipped on valid PR | `No tests/**/*.test.ts found — skipping.` | check `hashFiles('tests/**/*.test.ts')` — tests dir must exist |
| `npm ci` slow | `Cache not found for keys` in setup-node step | confirm `package-lock.json` unchanged from previous PR; otherwise expected |
| Multiple runs queued on same PR | duplicated job rows | `concurrency.cancel-in-progress: true` cancels prior runs on push — expected |
| Jobs never start | `The job was not started because recent account payments have failed` | org billing blocked — workflow uses self-hosted `ff-france-runner`; verify runner online via `gh api repos/lnlockly/agentflow-agents/actions/runners` |

### agentflow-landing E2E
| Symptom | Log signature for grep | Where to fix |
|---|---|---|
| Goal create returns 500 | `create-goal response was 500` | `agentflow-agents/src/routes/autonomous.ts` deadline parser |
| Card renders NaN | `assertNoNaN: rendered DOM contains [NaN` | `agentflow-landing/src/pages/AutonomousTab.tsx` formatters |
| Login redirect broken | `Test timeout … waiting for navigation to /cabinet` | `agentflow-landing/src/pages/LoginPage.tsx` redirect handler |
| Autonomous tab missing | `expected locator … "Автономно" to be visible` | `agentflow-landing/src/pages/DevicePage.tsx` tab registration |
| Prod under deploy | Flaky on first run, green on retry | `retries: 1` covers; if both fail, investigate `agentflow.website` |
