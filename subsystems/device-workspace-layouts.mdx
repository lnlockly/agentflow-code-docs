# Device workspace layouts

## TL;DR
A device's `/cabinet/devices/:id/live` page renders a CSS-grid workspace with three named slots (`main` / `side` / `bottom`). The three layout presets (`developer` / `simple` / `universal`) collapse onto a two-mode header pill — **«Простой ⇄ Профи»** (concept Phase 3, 5.4/5.7): Простой maps to the `simple` preset, Профи maps to `developer` (a device already on `universal` also reads as Профи). The preset id + per-slot overrides persist on `user_devices.layout_preset` / `user_devices.layout_config`. The per-slot swap menu shows only in Профи. Pages without a preset render the legacy MJPEG+composer grid; the «open workspace» button now opens into `simple` (Простой) by default.

**PR #573 (2026-05-31): «Простой» is one calm column.** The `simple` preset collapsed to a single `chat` panel (`side`/`bottom` = `null`) — no preview pane, no `activity`/`terminal`/`file-tree` tabs, no tab strip. The live page renders the `simple` preset through a dedicated `SimpleWorkspace` (not `UniversalWorkspace`), which mounts `Chat` with `args.variant === 'simple'`. That variant swaps the techy header for a slim status line («Агент сейчас работает…» / last result / idle), labels bubbles «Ты» / «Агент», renders agent action frames as quiet inline activity, and shows a friendly empty state with 3 example tasks (`SIMPLE_EXAMPLES`, briefs reused from `live.preset.*`). All power tools stay reachable behind «🔵 Профи». SSE/dispatch untouched.

## Data flow

```
              ┌──────────────────────────┐
GET /me       │ device.layout_preset      │
/devices/:id  │ device.layout_config      │
   ──────────►│ → mergeLayoutConfig() →   │
              │   ResolvedLayout          │
              └──────────┬───────────────┘
                         ▼
              ┌──────────────────────────┐
              │ UniversalWorkspace        │
              │ grid:                     │
              │   "main side"             │
              │   "bottom bottom"         │
              └──────────┬───────────────┘
                         ▼
              ┌──────────────────────────┐
              │ WIDGET_REGISTRY[id]       │
              │ → React.lazy component    │
              └──────────────────────────┘

PATCH /me/devices/:id { layout_preset, layout_config }
   from LayoutPicker → optimistic cache update
   → react-query invalidate on success
```

Mobile (&lt;768px) collapses the grid to a sticky-tab single-pane view; non-active slots stay mounted via `display:none` so terminal scrollback / editor content / chat history survive tab switches.

## DB / Env / API

- Tables: `user_devices.layout_preset TEXT`, `user_devices.layout_config JSONB`
- Routes:
  - `PATCH /me/devices/:id` body `{ layout_preset?, layout_config? }`
  - `GET /me/devices/:id/workspace/tree?root=&depth=`
  - `GET /me/devices/:id/workspace/file?path=`
  - `PUT /me/devices/:id/workspace/file?path=` body `{ content, encoding? }`
  - `WS /me/devices/:id/terminal` envelope `{ type: 'data'|'resize'|'exit', ... }`
- Allowlisted roots: `/workspace`, `/home/agent`, `/tmp`

## Presets

```ts
PRESETS.developer  = { main: 'preview-iframe', side: 'tabs:[chat,file-tree,code-editor]', bottom: 'tabs:[activity,terminal,file-tree]' }  // → «Профи»
PRESETS.simple     = { main: 'chat',           side: null,                               bottom: null }                                     // → «Простой» (rendered via SimpleWorkspace, PR #573)
PRESETS.universal  = { main: 'xvfb-stream',    side: 'stack:[artefact,chat]',             bottom: 'tabs:[terminal,file-tree,events]' }       // legacy → reads as «Профи»
```

Slot specs: bare widget id, `stack:[w1,w2]`, `tabs:[w1,w2,w3]`, or `null` (hidden).

Since PR #573 the `simple` preset is `chat`-only (`side`/`bottom` = `null`); the «лента событий» now rides inside the chat as inline action frames + a slim status line rather than a separate `activity` slot. `SimpleWorkspace` renders it directly, so `UniversalWorkspace`/`mergeLayoutConfig` are bypassed for Простой (per-slot overrides are ignored there). The two header pills map: `simple` → Простой, `developer`/`universal` → Профи (`presetToMode` in `LayoutPicker.tsx`). Clicking Профи always PATCHes `developer`; the live screen (`xvfb-stream`/`mjpeg-stream`) stays reachable in Профи via the per-slot swap menu.

## Failure modes

| Symptom | Log signature for grep | Where to fix |
|---|---|---|
| Unknown widget rendered as text | `Неизвестный виджет:` | `widgets/index.ts` registry — add id |
| File save 404 / 403 | `path not allowed` (server) | check `/workspace` allowlist |
| Editor blank on mobile | `Редактор кода доступен на десктопе` | by design — open on desktop |
| Main panel shows engineer copy «Preview URL пока не настроен» | (removed) `Preview URL пока не настроен` | now `live.preview.empty_title` in `PreviewIframe.tsx` — «Дай агенту первую задачу» + examples |
| Activity feed shows raw machine kinds (`coder`, `provisioning`) | `EVENT_KIND_LABELS` miss → raw kind | add the kind to `EVENT_KIND_LABELS` in `Activity.tsx` |
| Terminal "оборвано" repeatedly | `terminal ws close code=` | check `WS /me/devices/:id/terminal` backend |
