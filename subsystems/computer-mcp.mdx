# Computer MCP (desktop agent)

## TL;DR

Локальный Python MCP-сервер (`agentflow-computer-mcp`) ставится юзеру на Mac через `install.sh`, поднимается launchd-юнитом и держит WSS reverse-tunnel на `wss://agentflow.website/_devices/connect`. На стороне agentflow-agents активный коннект регистрирует `computer.*` тулы в `mcp-bridge` per-user — любой Eliza-агент из marketplace, прикреплённый к проекту `kind=desktop_agent`, может звать `computer.screen.capture`, `computer.mouse.click`, `computer.keyboard.type`, `computer.fs.read` (scoped), `computer.shell.exec` (whitelisted) и т.д.

Reverse-tunnel выбран чтобы обойти NAT/firewall на стороне юзера. Скоп enforcing на двух слоях: клиент проверяет args против `~/.agentflow/computer-scope.toml`, сервер — против `user_devices.scope_json`. `fs.write` и `shell.exec` всегда показывают native macOS confirm dialog даже если скоп их разрешает.

## Data flow

```
User's Mac (agentflow-computer-mcp launchd job)
   │
   │  ws_client.connect(wss://agentflow.website/_devices/connect,
   │     headers={x-api-key, x-device-id, x-enrollment-token})
   ▼
agentflow-agents devices-ws (/_devices/connect)
   │
   ├─ validate headers → exchange enrollment_token → device_secret
   ├─ INSERT/UPDATE user_devices SET status='online', last_seen=now()
   ├─ register ComputerDeviceProvider for user_id in mcp-bridge
   │     (computer.screen.*, computer.mouse.*, ... — list filtered by scope.allowed_tools)
   └─ start heartbeat loop (timeout 30s → mark offline + unregister)

Eliza agent inside project (kind=desktop_agent) runtime
   │  agent.callTool('computer.screen.capture', {})
   ▼
mcp-bridge.callTool
   │
   ├─ lookup ComputerDeviceProvider for caller user_id + device_id
   ├─ scope check args vs user_devices.scope_json  → 403 scope_denied
   ├─ forward over WS: { type: 'tool_call_request', id: uuid, name, args }
   │     (await result, timeout 60s, retry 1)
   ▼
ws_client (on Mac)
   │
   ├─ scope check args again (defense in depth)
   ├─ if tool ∈ confirm_before → osascript display dialog, abort on cancel
   ├─ dispatch to tool impl (tools/screen.py etc)
   └─ send: { type: 'tool_call_result', id, result|error }
   ▼
mcp-bridge
   │
   ├─ INSERT device_action_log (session_id, ts, tool, args, result, screenshot_url?)
   └─ return result to agent
```

## DB / Env / API

**Tables (drizzle, agentflow-agents schema):**

- `user_devices` — `id, user_id, name, last_seen, scope_json jsonb, status (online|offline), device_secret_hash, created_at, deleted_at`. Indexes: `(user_id, status)`.
- `device_sessions` — `id, device_id, agent_id, project_id, started_at, ended_at, tokens_used, cost_usd, max_actions, actions_used, status (active|complete|aborted)`.
- `device_action_log` — `id, session_id, ts, tool, args jsonb, result jsonb, screenshot_url, error`. Indexes: `(session_id, ts)`. Immutable (no UPDATE).

**Env (agentflow-agents):**

- No new server-side env. Uses existing `x-api-key` auth and TLS termination at Caddy.
- `DEVICE_HEARTBEAT_TIMEOUT_MS` (default 30000) — WS heartbeat-miss before marking offline. (env TBD verify post-deploy)
- `DEVICE_TOOL_CALL_TIMEOUT_MS` (default 60000) — forward-over-WS await ceiling. (env TBD verify post-deploy)

**Env / files (client Mac):**

- `~/.agentflow/auth.json` — mode 0600, JSON `{ api_key, device_id, device_secret }`. Written by `install.sh` after handshake.
- `~/.agentflow/computer-scope.toml` — user-editable scope file (mirror of server-side `scope_json`).
- `~/Library/Logs/agentflow-computer-mcp.log` — launchd stdout/err.

**Routes:**

- `GET    /me/devices` → list with `status` (online if heartbeat in last 30s).
- `POST   /me/devices` → body `{name}` → returns `{device_id, enrollment_token}` (one-time, 24h TTL).
- `POST   /me/devices/:id/scope` → body `{scope: DeviceScope}` → updates `scope_json`.
- `DELETE /me/devices/:id` → revokes (soft-delete + closes any active WS).
- `GET    /me/devices/:id/sessions?limit=` → list sessions for device.
- `GET    /me/devices/:id/sessions/:sid/log` → action log paginated.
- `GET    /me/devices/:id/sessions/:sid/stream` → SSE stream of new action_log rows.
- `WS     /_devices/connect` → reverse-tunnel upgrade.
- `GET    /install/computer-mcp.sh` → installer script (static).

**MCP tools registered per online device:**

```
computer.screen.capture(region?)
computer.mouse.click(x, y, button="left")
computer.mouse.move(x, y)
computer.mouse.scroll(dx, dy)
computer.keyboard.type(text)
computer.keyboard.key(name)
computer.keyboard.shortcut(combo)             # "cmd+space"
computer.window.list()
computer.window.focus(title)
computer.fs.read(path)                        # scoped
computer.fs.list(path)                        # scoped
computer.fs.write(path, content)              # scoped + native confirm
computer.shell.exec(cmd)                      # whitelist + native confirm
computer.clipboard.read()
computer.clipboard.write(text)
```

## Security model

1. **Enrollment token one-time, expires 24h.** Exchanged after first handshake for long-lived `device_secret` (hashed in DB).
2. **API key never in WS payload plaintext** — only in connect headers, TLS-only (`wss://`).
3. **Two-layer scope enforcement.** Server (`mcp-bridge`) rejects out-of-scope args before forwarding; client (`scope.py`) rejects again on receive (defense in depth).
4. **Hard-coded deny-paths fallback.** Even if `scope_json.deny_paths` is empty or removed, these are always blocked: `~/.ssh`, `~/.config`, `~/Library/Keychains`, `~/.aws`, `~/.gnupg`.
5. **`shell_whitelist` empty by default.** No shell command runs unless the owner explicitly added it via the scope editor.
6. **Native confirm dialog for `fs.write` and `shell.exec`** — always, even if scope allows. Cancelling returns `error: user_declined` to the agent.
7. **Budget cap.** `device_sessions.tokens_used * model_price > budget_usd` → session aborted (status=aborted, agent gets `error: budget_exceeded`).
8. **`max_actions_per_session` cap.** Default 50. Hard limit even if budget remains.
9. **Action log immutable.** Audit trail — INSERT only.
10. **Auth file mode 0600.** `install.sh` chmods.

## Failure modes

| Symptom | Log signature for grep | Where to fix |
|---|---|---|
| Device shows offline despite launchd running | `[device] heartbeat timeout user= device=` | `routes/devices-ws.ts:(TBD)` — heartbeat loop; check ws_client reconnect in `ws_client.py:(TBD)` |
| Tool call returns `scope_denied` | `[device] scope denied path=` / `[device] scope denied tool=` | Check `user_devices.scope_json.allow_paths` vs requested path; update scope at `/cabinet/devices/:id` |
| Tool call returns `timeout` after 60s | `[device] tool_call timeout id= name=` | Mac MCP froze or network dropped — `launchctl kickstart -k gui/$(id -u)/com.agentflow.computer-mcp` |
| Mac client crashes with permission error | `pyautogui FailSafeException` or `PIL.UnidentifiedImageError` in `~/Library/Logs/agentflow-computer-mcp.log` | macOS Accessibility / Screen Recording not granted; see [Device registration runbook](/runbooks/device-registration) |
| All tool calls return `user_declined` | `[device] confirm dialog cancelled tool=` | Owner cancelled native dialog; either widen scope (remove tool from `confirm_before`) or have the agent ask before retrying |
| WS connect rejected with 401 | `[device] invalid api-key` / `[device] enrollment_token expired` | Token TTL 24h passed before client first connected — re-issue from `/cabinet/devices` "Add device" |
| Session aborted mid-run | `[device] session budget exceeded session=` / `[device] session max_actions reached session=` | Raise `budget_usd` or `max_actions_per_session` in scope editor |
| Device row stuck `online` after launchd job stopped | `[device] heartbeat miss but ws not closed` | Stale WS reference in `mcp-bridge.ts:(TBD)`; restart `agentflow-agents` deploy |
| `fs.write` succeeds but file empty | `[device] fs.write zero bytes path=` | Client received empty `content` arg — likely caller bug, check upstream agent output |
| Enrollment token reused after first use | `[device] enrollment_token already consumed` | One-time semantics; issue a new token |
| pyautogui import fails on Apple Silicon Sonoma+ | `ImportError: ... Quartz` in startup log | Reinstall with `--no-cache pyobjc-framework-Quartz>=10.0` |

(All log strings above will become greppable substrings once Agent A/B push code — update this row set in the same PR that backfills line numbers.)
