# AgentFlow Desktop (forked Goose Desktop)

## TL;DR
AgentFlow Desktop is a rebranded fork of Block's Goose Desktop (Electron Forge app)
living in `lnlockly/agentflow-goose` at `ui/desktop/`. It ships the local `goosed`
binary (Rust, `crates/goose-server`) and runs in two modes: standalone (user chats,
goose codes + controls the machine) and platform-driven (device-bridge enrolls with
AgentFlow and runs the same `goosed` from `task_dispatch`). Phase 1 (this page's
current scope) rebrands the brand surface only — name, bundle id, icons, theme accent,
installer metadata, updater target, docs links. Internal identifiers (`goosed`,
`GOOSE_*` env, `goose://` deep-link scheme, `@aaif/goose-sdk` workspace pkg) are kept
unchanged on purpose.

## Data flow
```
                ┌──────────── AgentFlow Desktop (ui/desktop, Electron) ────────────┐
 Mode A chat ──►│ renderer (React+Vite) ─► main.ts ─► spawns local goosed (Rust)   │
                │                                       extensions: developer +     │
 Mode B WS ────►│ device-bridge ⇄ wss://agentflow.website/_agents/_devices/connect │
 (Phase 2)      │   task_dispatch ─► same goosed (POST /reply SSE) ─► result        │
                └──────────────────────────────────────────────────────────────────┘
                          LLM for both = `flow` gateway (GOOSE_PROVIDER=openai,
                          GOOSE_MODEL=flow, OPENAI_HOST=https://agentflow.website)
```

## DB / Env / API
- Env (build/runtime, unchanged identifiers): `GOOSE_PROVIDER`, `GOOSE_MODEL`,
  `OPENAI_HOST`, `GOOSE_BUNDLE_NAME`, `GITHUB_OWNER`, `GITHUB_REPO`, `APPLE_TEAM_ID`,
  `APPLE_ID`, `WINDOWS_CERTIFICATE_FILE`.
- Bundle id: `com.agentflow.desktop` (macOS). Deep-link scheme: `goose://` (kept —
  recipe/resume deep-links + server-emitted URLs depend on it).
- Updater target default: `github.com/lnlockly/agentflow-goose/releases/latest`.
- goosed headless dispatch (Phase 2): `POST /reply` (SSE), `/agent/*`, `/sessions/*`,
  `/schedule/*` in `crates/goose-server`.
- Docs links repointed: `goose-docs.ai` → `docs.agentflow.website`; issues →
  `github.com/lnlockly/agentflow-goose/issues`.
