# Research knowledge sidebar

## TL;DR

The Knowledge sidebar is a right-rail accordion inside the `AgentWorkspace`
chat tab. It surfaces three ingest controls (URL / PDF / YouTube) against the
research-ingest endpoints landed in PR #320, plus a polled document list for
status visibility. Visible only when `agent.category === 'researcher'` AND the
URL carries `?sidebar=knowledge`, so it stays out of the way for non-research
agents.

## Data flow

```
User opens /my/agents/<slug>?sidebar=knowledge
        │
        ▼
AgentWorkspace fetches /agents/:slug → agent.category check
        │
        ▼ (researcher only)
KnowledgeSidebar mounts
        │
        ├─ URL block      → POST /agents/:slug/knowledge/url       (5¢)
        ├─ PDF block      → POST /agents/:slug/knowledge           (multipart)
        └─ YouTube block  → POST /agents/:slug/knowledge/youtube   (5¢ captions
                            / 15¢+ whisper if checkbox toggled, fallback=whisper)
        │
        ▼
GET /agents/:slug/knowledge → list rows
        │
        ▼
useEffect polls every 4000ms while any row has status='processing'
```

## DB / Env / API

- Backend endpoints (live since PR #320): see `subsystems/research-ingest.mdx`
  for the server side. The frontend only consumes them.
- No new env vars. The sidebar reads `VITE_AGENTS_URL` indirectly via
  `agentsBaseUrl` for the multipart fetch fallback (existing constant).
- URL params: `?sidebar=knowledge` toggles visibility. Other tabs (knowledge,
  settings) are unaffected — sidebar mounts only inside `tab === 'chat'`.

## Deep-link auto-clone (`/agents/new?preset=<slug>`)

The `/research` page's template cards link to
`/agents/new?preset=<preset_slug>&category=researcher`. `CreateAgentPage`
reads the `preset` query param on mount; when present it calls
`POST /me/agents/from-preset` via the `cloneFromPreset` helper and redirects
to `/agents/<minted_slug>` with `replace: true`. Empty `preset` falls through
to the existing blank-form render.

| Path | Role |
|---|---|
| `agentflow-landing/src/pages/CreateAgentPage.tsx:108` | `useEffect` reads `preset` from `useSearchParams`, drives the auto-clone. |
| `agentflow-landing/src/lib/agentsApi.ts:1346` | `cloneFromPreset` helper — wraps `POST /me/agents/from-preset`. |
| `agentflow-landing/src/pages/Research.tsx:380` | Template card `<Link to>` that injects the params. |
| `agentflow-agents/src/routes/me-presets.ts:117` | Backend handler — resolves preset, picks unique slug, provisions Eliza row. |

Failure modes: a 400 `preset_not_found` (typo / removed JSON file) or network
error keeps the user on `/agents/new` and surfaces the message in the form's
error banner — they can still build an agent by hand.
