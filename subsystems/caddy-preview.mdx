# Caddy preview sidecar

## TL;DR

Каждый project-pod несёт Caddy sidecar на порту 8080. Читает `/workspace/.runtime/plan.json` и сам выбирает режим: **static** (раздаёт `dist/` или `pick_root` подкаталог), **proxy** (forward в backend на `127.0.0.1:PORT`), **stub** (HTML «Workspace ready — deploying...»). Stub-страница умышленно sha256-hashed в `placeholder-hashes.json`, чтобы preview-gate не финализировал проект, пока coder реально не запустил приложение. Гейт покрывает kinds: `landing`, `spa`, `mini_app`, `tg_profile_bundle` (визитка).

## Data flow

```
expose_public tool / runtime-supervisor.deploy
   ↓ writes /workspace/.runtime/plan.json { mode: "static" | "proxy", root | upstream }
   ↓ reloads Caddy admin API: curl -X POST 127.0.0.1:2019/load
Caddy reads plan.json on each request
   ↓
mode=static  → file_server { root /workspace/<root> } (PICK_ROOT_SUBDIR_BLOCK fallback)
mode=proxy   → reverse_proxy 127.0.0.1:<PORT>
plan.json missing → serve HTML stub (caddy.ts:544) "Workspace ready — deploying..."
   ↓
External client GET https://<slug>.preview.agentflow.dev/
   ↓
preview-placeholder.probePreviewUrl
   ↓ title=/Workspace ready/  OR  sha256 ∈ deny-list  OR  body<800b  → placeholder=true
   ↓ status=200 + body≥2048b + no markers           → ready=true
preview-gate.checkPreviewGate (per-kind dimensions) → finalize or hold
```

## DB tables / env / API surface

**DB:**
- `projects.preview_url`, `projects.workspace_project_name` — anchor для probe.

**Env:**
- `PREVIEW_GATE_STRICT=true` — отказ финализировать на placeholder.
- `DEP_INSTALL_AGENT=1` — fallback на LLM-агента при failed npm install.

**Configs / API:**
- `agentflow-agents/src/config/placeholder-hashes.json` — sha256 deny-list (stub HTML, default Caddy welcome, common boilerplate index pages).
- Caddy admin API на `127.0.0.1:2019` (inside pod only).
- Caddy listens 8080 (cluster) → ingress 80/443 наружу.

## Failure modes

| Симптом | Лог-строка для grep | Где починить |
|---|---|---|
| Preview зависает на «Workspace ready...» | `caddy_workspace_ready_title` | `services/pingers/preview-placeholder.ts:125` |
| `tg_profile_bundle` застрял в `done` пока preview — placeholder | `preview_gate_blocked` | `services/pingers/preview-placeholder.ts:34` (добавлен в `STATIC_PREVIEW_KINDS`) |
| Static SPA отдаёт 404 на subroutes | `pick_root_no_index_html` | `helpers/caddy.ts:29` (PICK_ROOT_SUBDIR_BLOCK) |
| `dist/` собран но Caddy всё ещё stub | `placeholder_repoint_skipped` | `services/pingers/placeholder-repoint.ts:94` |
| Sha256 совпал с известным boilerplate | `placeholder_hash_match` | `src/config/placeholder-hashes.json` |
| `auto_install_deps` падает (peer deps) | `auto_install_deps_failed` | `helpers/caddy.ts:129` |
| Body < TINY_BODY_BYTES | `tiny_body_placeholder` | `preview-placeholder.ts:41` |
