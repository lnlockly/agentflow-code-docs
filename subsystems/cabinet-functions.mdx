# Cabinet «Функции»

## TL;DR
The «Функции» catalog (`/cabinet/functions`) is a витрина of one-click AI
functions: the user types one brief/prompt and gets ONE real artifact back
synchronously — a post, a market analysis, content ideas, an image, an MP4, or
a live landing. Each card calls a thin `POST /me/functions/*` endpoint on
agentflow-agents; «Сделать лендинг» reuses the projects pipeline instead.

## Data flow
```
CabinetFunctions.tsx card
  → agentsApi.generateFunction{Copy,Research,Ideas,Image}(brief|prompt)
    → POST /me/functions/{copy,research,ideas,image,video}  (x-api-key / session)
      → requireSession → ownerUserId = session.sub
      → text functions: services/text-function.ts
          → invokeAI(ModelType.TEXT_LARGE, {messages}, {ownerUserId, agentSlug})
          → flow alias → live provider (e.g. gpt-5.3-codex), billed to owner
      → { ok:true, text }  (or { ok:false, error, detail })
  → card renders the text inline + a «Копировать» button
```

The text functions return plain text (no JSON parse): the model reply is
trimmed; an empty trimmed reply throws `text_function_empty_llm_reply`.

## DB / Env / API
- Routes: `POST /me/functions/{copy,research,ideas,trends,funnel,slides,voice,image,video}`.
- Auth: `requireSession` (cabinet session cookie OR `x-api-key: af_live_…`).
- LLM (text): `invokeAI(ModelType.TEXT_LARGE)` → `flow` alias. No model strings
  hardcoded; provider resolution + priority live in `llm_provider_configs` /
  `llm_model_aliases`. `ownerUserId` carries BYOK lookup + billing.
- Voice: `invokeAI(ModelType.TEXT_TO_SPEECH)` → ElevenLabs handler. Voice id is
  NOT hardcoded — `FUNCTIONS_VOICE_ID` env, else the handler default
  `xdADm9fX0hNasTe0AGW0`. mp3 persisted via `persistMultimodalArtifact`
  (`/files/multimodal/<sha>.mp3`). Latin runs are transliterated to Cyrillic
  before TTS (ElevenLabs mispronounces Latin mid-Russian).
- Env (voice): `ELEVENLABS_API_KEY` (required), `FUNCTIONS_VOICE_ID` (optional),
  `UPLOAD_DIR` + `UPLOADS_PUBLIC_BASE` (artifact persistence).
- No new tables. trends/funnel/slides add no env.

| Voice card 502 for every text | `voice generation failed` + `all_providers_failed for TEXT_TO_SPEECH: elevenlabs=elevenlabs 401 ... payment_issue` | ElevenLabs invoice unpaid — pay it OR set `OPENAI_API_KEY` for the BYOK-OpenAI TTS handler. No code change. Observed 2026-06-01. |
| Voice mispronounces a Latin brand | n/a (audio) | `transliterateLatinTokens` (`voice-function.ts:74`) rewrites Latin→Cyrillic only when Russian present |

## Verification (live, flow router)
Owner-key smoke (lead runs post-merge):
```bash
curl -X POST https://agentflow.website/_agents/me/functions/research \
  -H "x-api-key: af_live_…" -H "Content-Type: application/json" \
  -d '{"brief":"рынок доставки кофе в Москве"}'
```
Verified 2026-06-01 in-pod via `invokeAI(TEXT_LARGE)` (model `gpt-5.3-codex`
through the `flow` alias, owner user=1): research returned 5 markdown sections
(аудитория / конкуренты / риски / отстройка); ideas returned 7 numbered post
hooks with formats (reels / сторис / рассылка). Both brief-derived, no fake
stats/links, no «бесплатно».

Batch-2 verified 2026-06-01 in-pod (same router, owner user=1, brief =
«барбершоп в Питере, мужские стрижки и уход за бородой»):
- **trends** — 5+ numbered viral angles (до/после Reels, POV кресло, разбор
  ошибок ухода, питерский стиль недели), brief-derived.
- **funnel** — 4-step touch sequence with ready example copy per step, ending
  on «закрытие на запись / оплата».
- **slides** — parsed a 6-item JSON array into `{title, body}` slides (крючок →
  призыв «Запишись в барбершоп»); fence-tolerant parser handles ```json wrap.
- **voice** — code path reached the ElevenLabs handler with the transliterated

  `'Привет от Агентфлов и Кукоин'`; a pure-English string is left untouched.
