# Workspace UI — /account/projects/:id

## TL;DR
The owner-only project page mounts `ProjectWorkspace` (v0.dev split layout:
chat column ↔ Preview/Code/Terminal/Tools tabs). The thinner `WorkspaceV2`
(2-column center+rail with breadcrumbs) still backs `/workspace/:id` for
shared/public surfaces. Owner directive 2026-05-18 reverted the
`/account/projects/:id` route back to `ProjectWorkspace` after a quiet swap
to `WorkspaceV2` made the page feel thin.

## Data flow

```
                  /account/projects/:id  ──┐
                                           │ owner-only (AccessGate)
                                           ▼
                                  ProjectWorkspace
                                  ├── useProjectData(id)  → /me/projects/:id
                                  ├── ProjectHeader (LiveToggle, status, stop)
                                  ├── ProgressBar / ChipStrip / ProvisioningBanner
                                  ├── LEFT: ChatPane · TeamRosterRail · ProjectChat
                                  │         · TokenHealthBar · OwnerInputBar
                                  └── RIGHT: TabBar →
                                       Preview · Code · Terminal · Git ·
                                       Tools · Tasks · Brief · Secrets ·
                                       Marketplace · AiModels · Metrics ·
                                       Domain · Firehose · Settings

                  /workspace/:id  ──────────┐
                                           ▼
                                  WorkspaceRouter ── ?v2=1 ── WorkspacePageV2
                                                  └── else  ── WorkspaceV2
                                                              (AppShellV2 +
                                                               Preview · Files ·
                                                               Plan · Events ·
                                                               Team · Secrets)
```

## DB / Env / API
- Routes consumed: `GET /me/projects/:id`, `POST /me/projects/:id/messages`,
  `POST /me/projects/:id/approve|reject|repropose|stop`,
  `GET /me/projects/:id/files`.
- Env: none owner-facing; `VITE_FEED_ENABLED` gates an unrelated route.
- Tables: `projects`, `project_events`, `project_artifacts`, `plan_tasks`,
  `project_team` (read-only from the page).

## Failure modes
