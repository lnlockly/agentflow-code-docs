# Multi-agent runtime (desktop daemon)

## TL;DR
The daemon used to run one global LLM loop. The multi-agent runtime
turns it into a host process that fans `task_dispatch` frames out to
N independent slots — each owns its own `asyncio.Queue`, Playwright
`BrowserContext`, persona, scope, and USD budget. v1 is opt-in via
`AGENTFLOW_MULTI_AGENT=1`; legacy single-slot installs auto-migrate
into `~/.agentflow/agents/default/` on first boot.

## Data flow
```
        ┌─────────────── agentflow-desktop process ───────────────┐
ws ──►  │ WSClient ─► task_dispatch(agent_id) ─► AgentRouter      │
        │                                          │              │
        │                                          ▼              │
        │                          slot[id].queue (asyncio.Queue) │
        │                                          │              │
        │                                          ▼              │
        │              _consume(slot) → handler → BrowserContext  │
        │                                                         │
        │ AgentSocket (UNIX) ─► list/pause/resume/create          │
        └─────────────────────────────────────────────────────────┘
```

## DB / Env / API
- Per-slot dir: `~/.agentflow/agents/<slot_id>/`
  - `scope.toml` — same shape as legacy `computer-scope.toml`
  - `persona.txt` — persona prompt fragment
  - `memory.db` — sqlite (cloned from `autonomous/schema.py`)
  - `logs/<YYYY-MM-DD>.jsonl`
- Env:
  - `AGENTFLOW_MULTI_AGENT=1` — opt-in for v1
  - `AGENTFLOW_AGENT_SOCKET` — override control-socket path (default `/tmp/agentflow.sock`)
- Control socket protocol (line-delimited JSON, UNIX only in v1):
  ```jsonc
  {"method": "list"}
  {"method": "create", "name": "trader", "persona": "trade", "scope_path": "~/scopes/trader.toml"}
  {"method": "pause",  "id": "trader"}
  {"method": "resume", "id": "trader"}
  {"method": "logs",   "id": "trader", "n": 100}
  ```
- WS protocol additions (server work tracked separately in `agentflow-agents`):
  - `task_dispatch` frames gain optional `agent_id`; unknown ids fall back to `default`.

## Failure modes
| Symptom | Greppable log | Where to fix |
|---|---|---|
| Slot stuck in `crashed` after handler raised | `[agent-router] slot %s crashed` | `agents/router.py:_consume` |
| Browser pool refuses new slot | `[browser-pool] cap reached` | `agents/pool.py:acquire` |
| Second daemon fails on socket bind | `[agent-socket] bind failed` | `agents/socket.py:serve` |
| Legacy install missed migration | `[agent-bootstrap] legacy migrate` (absent in logs) | `agents/bootstrap.py:migrate_legacy` |
| `BudgetExhausted` raised mid-task | `budget exhausted: requested ...` | `agents/budget.py:deduct` |
| Unknown `agent_id` arrives on ws | `[agent-router] unknown agent_id=` | `agents/router.py:dispatch` |
