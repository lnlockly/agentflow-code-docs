# code-exec MCP

## TL;DR

Streamable-HTTP MCP сервер, который kubectl-exec'ит команды внутрь StatefulSet pod'а проекта (`project-<slug>-0` в vcluster). Один процесс на API-под, multi-tenant: каждая tool-call резолвит `workspace_project_name` → `projects` row → проверяет ACL, AES-расшифровывает `project_secrets`, прокидывает в `exec`. Workdir invariant (`WORKDIR_STRICT`) ловит дрейф `/workspace` между write_file и exec, surfaces typed errors (`WORKSPACE_DRIFT`, `workdir_invariant_failed`, `empty_workspace_on_expose`) которые pool-worker трактует как retryable.

## Data flow

```
Coder agent (Eliza/Maestro) → MCP client (streamable-http)
   ↓ POST /mcp { tool: "write_file", args: { workspace_project_name, path, content } }
handleCodeExecMcp (index.ts:2968)
   ↓
resolveProjectByWorkspace (workspace-resolve.ts:33)
   ↓ acl check: project.owner_user_id == caller.user_id
loadProjectSecretValues — AES-256-GCM unseal через AGENTS_MASTER_KEY
   ↓
checkInvariant (pre) — snapshot /workspace inode/mtime
   ↓
kubectlExec — kubectl exec -n <ns> project-<slug>-0 -- sh -c '<cmd>'
   ↓
checkInvariant (post) — если drift → WORKSPACE_DRIFT typed error
   ↓ return { ok, stdout, stderr, drift? }
pool-worker / agent — если drift → ERROR_MARKERS hit → autoRetry chain
```

## DB tables / env / API surface

**DB:**
- `projects` — `workspace_project_name`, `owner_user_id` (ACL anchor).
- `project_secrets` — sealed AES-256-GCM, source ∈ \{platform, user_brief, owner\}, ключи: `BOT_TOKEN`, `OPENROUTER_API_KEY`, и т.д.

**Env:**
- `AGENTS_MASTER_KEY` — base64-32 master key для seal/unseal.
- `WORKDIR_STRICT=1` — включает invariant detection.
- `KUBECONFIG_PATH` — путь к kubeconfig для vcluster (per-user).
- `AGENTFLOW_INTERNAL` — base URL для internal callbacks (runtime-supervisor → code-exec).

**API surface:**
- `POST /mcp` — streamable-http MCP transport (mounted в `server.ts`).
- Tools: `write_file`, `write_file_b64`, `upload_to_storage`, `exec`, `start_service`, `expose_internal`, `expose_public`, `read_file`, `list_dir`, `delete_path`.
- Statics: `STATIC_PREVIEW_KINDS = ['spa','landing','mini_app']` (workspace-resolve.ts:567), `BUILD_OUTPUT_DIRS = ['dist','build','out','public']` (workspace-resolve.ts:563).

## Failure modes

| Симптом | Лог-строка для grep | Где починить |
|---|---|---|
| Coder пишет в `/workspace/src/`, потом `exec npm run build` падает с ENOENT | `WORKSPACE_DRIFT` | `helpers/workspace-resolve.ts:397` (assertWorkspaceMatches) |
| `expose_public` отдаёт 500 на пустой workdir | `empty_workspace_on_expose` | `index.ts:1890` (expose_public) |
| Agent пишет файл в wrong cwd | `workdir_invariant_failed` | `helpers/workspace-resolve.ts:225` (checkInvariant) |
| `kubectl exec` висит | `kubectl_exec_timeout` | `helpers/kubectl.ts:40` (SIGKILL after timeout) |
| Decrypt fail на secrets | `seal_unseal_failed` | `services/seal.ts:88` (unsealString) |
| ACL bypass попытка | `code_exec_acl_denied` | `helpers/workspace-resolve.ts:33` (resolveProjectByWorkspace) |
