# Windows tray app

## TL;DR
Lightweight Windows-side counterpart to `macapp/`. Built on `pystray` + native menu. Surfaces
local daemon status, agent slots, the last 5 cloud goals, daily budget, plus quick actions
(open cabinet, restart daemon, autostart on login). Implementation lives under
`agentflow-computer-mcp/src/agentflow_computer_mcp/winapp/`; the `winapp/` root dir holds
the README + bundled icon assets so PyInstaller picks them up automatically.

**v0.5.0 ships the tray with the installer.** `agentflow-desktop-setup.exe` now bundles
a second PyInstaller onefile `agentflow-tray.exe` alongside the daemon. The wizard:

1. copies `agentflow-tray.exe` into `%LOCALAPPDATA%\AgentFlow\`,
2. writes `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\AgentFlowTray = "<path>"`,
3. spawns the tray immediately (detached process).

After install the user sees the AgentFlow icon in the system tray without opening
a terminal — parity with the Mac DMG menu-bar app. A wizard checkbox «Запускать иконку
в трее при старте Windows» (default ON) controls the Run-key write + the immediate spawn.

## DB / Env / API
- Tables: none (state held in memory).
- Env: `AGENTFLOW_API_KEY` (or `~/.agentflow/auth.json`) — read by `cli.rest_client.resolve_api_key`.
- Routes hit: `GET /me/autonomous/goals`, `GET /me/autonomous/budget` on `agentflow.website/_agents`.
- Local IPC: `cli.socket_client.call("list" | "pause", ...)` — UNIX socket today, Windows named pipe pending (#94).
- Registry: `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\AgentFlowTray`.
  - Source-mode (pip install): `"<pythonw>" -m agentflow_computer_mcp.winapp` (written by `winapp.autostart.install`).
  - Installer-mode (v0.5.0+): `"<LOCALAPPDATA>\AgentFlow\agentflow-tray.exe"` (written by `installer/setup_gui.py:register_tray_autostart`).

### v0.5.0 autostart registry table

| Key | Value | Writer |
|---|---|---|
| `HKCU\…\Run\AgentFlowTray` | `"%LOCALAPPDATA%\AgentFlow\agentflow-tray.exe"` | `setup_gui.register_tray_autostart` |
| Scheduled Task `AgentFlowDesktop` | `"%LOCALAPPDATA%\AgentFlow\agentflow-desktop.exe" --daemon` | `setup_gui.register_scheduled_task` |

Both writers are idempotent (Run-key uses `SetValueEx`, schtasks uses `/F`).

## Failure modes
| Symptom | Log signature for grep | Where to fix |
|---|---|---|
| Header stuck on "Локальные команды требуют Windows-pipe — в работе" | `"Windows: локальный socket пока не поддерживается"` (raised in `cli/socket_client.py:28`) | ship Windows named-pipe variant (#94) |
| Tray header reads "Демон не запущен" on macOS while daemon is up | `socket not found:` from `cli/socket_client.py:30` | check `/tmp/agentflow.sock`, `agentflow daemon start` |
| Goals submenu shows "Не авторизован" | `NotAuthenticated` in `cli/rest_client.py:42` | `agentflow login --api-key …` |
| Autostart install raises `UnsupportedPlatform` | `"autostart only works on Windows"` (`winapp/autostart.py:34`) | run on Windows or inject `opener=` for tests |
| pystray missing in the venv | `pystray not installed:` (`winapp/tray.py:43`) | `pip install pystray Pillow` |
