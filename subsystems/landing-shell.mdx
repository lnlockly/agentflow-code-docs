# Landing app shell + design tokens

## TL;DR

All v2 pages (`/studio`, `/projects`, `/marketplace`, `/my/agents`, `/inbox`, `/triggers`, `/account/usage`, `/account/billing`, `/account/settings`, `/admin/hub`, `/status`) wrap their bodies in `AppShellV2`. The shell renders a 240px sidebar + 70px topbar with a single set of design tokens defined in `dark-tokens.css`. Two sidebar variants exist: the regular WORKSPACE + INSIGHTS nav for everyday browsing, and an ADMIN nav that activates only when the user is on `/admin/*` AND `user.is_admin === true`. Admin entries never bleed into the regular workspace shell.

## Admin section split (2026-05-15)

Owner complaint: admin links surfaced inside the regular workspace shell. Fix:

1. `AppShellV2` swaps `WORKSPACE_NAV + INSIGHTS_NAV` → `ADMIN_NAV` when `isAdminPath(location.pathname) && user.is_admin` is true. A "Back to workspace" row sits above the admin section.
2. Admin avatar dropdown gets an "Admin" entry only when `user.is_admin === true` — one click to `/admin/hub`.
3. `AccountHeader.tsx` dropped its inline `🛡 Admin` pill — admin entry no longer bleeds into Hub/Account chrome.
4. `Hub.tsx` extraNav dropped its admin link for the same reason.

## Routes wired in the shell

`agentflow-landing/src/main.tsx` mounts:

- `/admin` → redirect to `/admin/hub`
- `/admin/hub` → `AdminHubV2` (gated by `AccessGate`)
- `/account/admin/projects`, `/admin/campaigns`, `/admin/ads`, `/admin/flow`, `/admin/billing`, `/admin/workspace` — admin-only pages, all wrapped in `AppShellV2` so the ADMIN_NAV sidebar shows automatically.

## Failure modes

| Symptom | Log / grep signature | Where to fix |
|---|---|---|
| Admin sees admin links inside `/studio` or `/projects` | `ADMIN_NAV` rendering when `isAdminPath` returns false | `AppShellV2.tsx:87` — extend `isAdminPath` |
| Non-admin lands on `/admin/hub` and bounces to `/account` | `AdminHubV2` `Navigate to="/account"` | `AdminHubV2.tsx:62` — gate uses `user.is_admin` |
| Hardcoded hex in a new page diverges from the palette | `grep -nE "'#[0-9A-Fa-f]{3,8}'" src/pages/<page>.tsx` | Replace with `var(--af-*)` from the table above |
