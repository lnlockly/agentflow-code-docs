# Matrix Chat

> **Status: planned 2026-05-21** — spec и plan написаны, Phase 1 (Dendrite deploy) в работе. Эта страница обновляется по мере реализации.

## TL;DR

Self-hosted Dendrite homeserver на k3s + кастомный React UI поверх `matrix-js-sdk`. Юзер логинится в AgentFlow обычным способом, при заходе на `/chat` фронт получает Matrix access_token через bridge endpoint (`agentflow-agents POST /me/chat/token`), который auto-provision'ит Matrix-юзера через shared-secret registration с deterministic-password derivation. Федерация и E2EE отключены в MVP. Mobile-клиент и Telegram bridge — следующие фазы.

## Data flow

```
Browser /chat
   │
   ├──[1]──> agentflow.website POST /me/chat/token  (AF JWT cookie)
   │           │
   │           ├── verify AF session (existing middleware)
   │           ├── compute internal_password = HMAC(MATRIX_AUTH_KEY, af_id)
   │           ├── try /login → 200 (existing user) or 403 (new)
   │           ├── if 403: shared-secret register → get access_token in response
   │           └── return { homeserver, user_id, access_token, device_id }
   │
   ├──[2]──> matrix-js-sdk initialized with token
   │
   ├──[3]──> matrix.agentflow.website/_matrix/client/v3/sync (long-poll)
   │
   └──[4]──> matrix.agentflow.website/_matrix/client/v3/rooms/{id}/send/m.room.message
              │
              └── Dendrite → Postgres → fanout to other connected /sync clients
```

## DB / Env / API

### Postgres
- DB: `dendrite` (рядом с `agentflow` в `agentflow-postgres-97fb67469-69298`)
- User: `dendrite` (отдельный, чтобы limit blast radius)
- Dendrite авто-создаёт ~20 таблиц при первом старте (`account_accounts`, `roomserver_*`, `syncapi_*`, и т.д.)

### Media storage
- Local PVC `dendrite-media` 50Gi (Dendrite не имеет S3 backend; миграция на MinIO — открытый item)

### Env (agentflow-agents)
- `MATRIX_HOMESERVER_URL` — internal cluster URL, обычно `http://dendrite:8008`
- `MATRIX_PUBLIC_URL` — `https://matrix.agentflow.website` (отдаётся фронту)
- `MATRIX_AUTH_KEY` — HMAC key для deterministic-password derivation (никогда не покидает agentflow-agents)
- `MATRIX_REGISTRATION_SHARED_SECRET` — shared с Dendrite ConfigMap, для `/_synapse/admin/v1/register`
- `MATRIX_SERVER_NAME` — `agentflow.website` (не `matrix.agentflow.website` — server_name по Matrix спеке)

### Dendrite config (ConfigMap)
- `global.server_name: agentflow.website`
- `global.disable_federation: true`
- `global.database.connection_string` — postgres URL
- `client_api.registration_disabled: true` (public reg off)
- `client_api.registration_shared_secret` — same as `MATRIX_REGISTRATION_SHARED_SECRET`
- `media_api.*` — MinIO S3 backend creds

### Routes (новые на agentflow-agents)
- `POST /me/chat/token` — issue Matrix access_token (auto-provision на первом вызове)
- `POST /me/chat/rooms` *(phase 3+)* — create room with current user as admin
- `POST /me/chat/invite` *(phase 3+)* — invite by AF user_id

### Matrix endpoints (наружу)
- `https://matrix.agentflow.website/_matrix/client/v3/*` — standard Matrix Client-Server API
- `https://matrix.agentflow.website/_matrix/media/v3/upload?filename=<...>` — binary upload, `Content-Type: <mime>` + raw body, returns `{ content_uri: "mxc://agentflow.website/<id>" }`
- `https://matrix.agentflow.website/_matrix/client/v1/media/download/agentflow.website/<id>` — authenticated full-size fetch (v1.11+ requires `Authorization` header or `access_token` query)
- `https://matrix.agentflow.website/_matrix/client/v1/media/thumbnail/agentflow.website/<id>?width=&height=&method=scale` — authenticated server-rendered thumbnail
- `https://agentflow.website/.well-known/matrix/server` — server discovery
- `https://agentflow.website/.well-known/matrix/client` — client discovery

### Attachment flow (m.image / m.file)
1. Browser `POST /_matrix/media/v3/upload` with file body → `mxc://...`.
2. Browser `PUT /_matrix/client/v3/rooms/{id}/send/m.room.message/{txn}` with `{ msgtype: "m.image" | "m.file", body: <filename>, url: <mxc>, info: { mimetype, size, w?, h? } }`.
3. Other clients see the event via /sync; `agentflow-landing/src/chat/matrixApi.ts#parseSync` builds `MatrixAttachment` with `thumbnailUrl` + `downloadUrl` already auth-stamped.
4. `<img src={thumbnailUrl}>` works because `mxcToHttp` embeds `access_token` as query param (browsers can't attach Authorization to plain img tags).

## Failure modes

| Симптом | Лог-строка для grep | Где починить |
|---|---|---|
| Юзер не может залогиниться в чат | `[chat-bridge] login failed after register` | `MATRIX_AUTH_KEY` ротировался — нужен fallback через `/_dendrite/admin/resetPassword/` |
| Registration возвращает 401 invalid_mac | `[chat-bridge] register mac mismatch` | `MATRIX_REGISTRATION_SHARED_SECRET` env != `registration_shared_secret` в Dendrite ConfigMap |
| Сообщения не сохраняются | `pq: connection refused` в Dendrite logs | Postgres connectivity, проверить `dendrite` user creds + NetworkPolicy |
| Media upload 413 | `nginx 413 Request Entity Too Large` | Ingress `proxy-body-size` поднять до 50m для `matrix.agentflow.website` |
| `/sync` отрубается через 30c | `sync request closed` в browser console | Ingress timeout — поднять до 60s для `/_matrix/client/v3/sync` |
| `.well-known/matrix/server` 404 | `404 GET /.well-known/matrix/server` в landing logs | `agentflow-landing/public/.well-known/matrix/` не задеплоен или Vite plugin не копирует |
| User auto-provision 409 conflict | `M_USER_IN_USE` в bridge logs | Race condition при первом одновременном логине — добавить retry на GET после 409 |
| Voice/video не работает | `WebRTC: no ICE candidates` | Phase 2+, TURN не настроен (coturn out of scope MVP) |
| Image preview blank, dev tools показывают 401 | `401 M_MISSING_TOKEN` на `/media/thumbnail/...` | `mxcToHttp` должен добавлять `access_token` query (Authorization header нельзя на `<img>`) — Dendrite v1.11+ media auth обязателен |
| Upload падает 413 на >50 MiB | `413 Request Entity Too Large` в browser console | Composer cap = 50 MiB, совпадает с ingress `proxy-body-size`. Поднять оба, если меняем cap |
| Dendrite CrashLoopBackOff после bridge PR | `Invalid config file: open /etc/dendrite/appservices/<bridge>.yaml: no such file or directory` | `app_service_api.config_files` в `k8s/dendrite-config.yaml` ссылается на bridge registration, но Secret `mautrix-<bridge>-registration` не создан. `optional: true` на projected volume позволяет поду стартовать БЕЗ Secret'а, но Dendrite фаталит на отсутствующий файл. Fix: либо закончить bootstrap bridge (см. `k8s/mautrix-<bridge>.yaml` header — создать DB, secrets, apply manifest), либо убрать строку из `config_files` до bootstrap. **Никогда не добавляй новую строку в `config_files` пока `kubectl get secret mautrix-<bridge>-registration` не вернёт ресурс.** Инцидент 2026-05-22: whatsapp.yaml |

## Lobby room (`#lobby:agentflow.website`)

> **Shipped 2026-05-21.** Public chat where every authenticated user lands on first SSO bounce. Element renders it in the sidebar; users can write messages, see other AF users, and tag the platform bots.

### Files (with line refs)

| Path | Role |
|---|---|
| `agentflow-agents/src/services/matrix-onboarding.ts:223` | `ensureLobbyRoom` — alias-resolve → createRoom from af-helper, race-safe |
| `agentflow-agents/src/services/matrix-onboarding.ts:323` | `ensureLobbyRoomAtBoot` — wrapper that loads bot roster + calls `ensureLobbyRoom` |
| `agentflow-agents/src/services/matrix-onboarding.ts:82` | `ensureLobbyJoin` — per-bounce idempotent `/join` with the user's own token |
| `agentflow-agents/src/server.ts:405` | Boot-time call (60s delay so bots runner seeds `matrix_bots` first) |
| `agentflow-agents/src/routes/element-sso.ts:323` | Bounce-time `ensureLobbyJoin` call gated by `chat_lobby_joined_at` |
| `agentflow-agents/src/services/env.ts:175` | `MATRIX_LOBBY_ALIAS` (default `#lobby`), `MATRIX_LOBBY_ENABLED` (default `1`) |
| `agentflow-agents/migrations/2026-05-21e-chat-lobby-joined.sql:1` | `users.chat_lobby_joined_at TIMESTAMPTZ NULL` |
| `agentflow-agents/tests/matrix-onboarding.test.ts:381` | `ensureLobbyRoom` tests (idempotency, create, race, override) |

### Idempotency model

Two layers:

1. **Room provisioning.** `ensureLobbyRoom` GETs `/_matrix/client/v3/directory/room/<alias>` first. On 200 → return room_id, no further calls. On 404 → POST `/createRoom`. On `M_ROOM_IN_USE` race (concurrent pod cold-starts winning the same alias) → re-resolve. Steady-state cost: one GET per boot.
2. **Per-user join.** The bounce handler reads `users.chat_lobby_joined_at` — if NULL, POSTs `/join/<alias>` as the user, then flips the column. Matrix's `/join` is a server-side no-op on already-member, so a missed DB write just costs one redundant round-trip on the next bounce.

### Room shape

| Setting | Value | Why |
|---|---|---|
| `preset` | `public_chat` | Joinable by alias without invite |
| `visibility` | `public` | Surfaced in the homeserver's room directory |
| `room_alias_name` | `lobby` | Canonical alias `#lobby:agentflow.website` |
| `name` | `Lobby` | Element sidebar label |
| `topic` | `Общий чат всех пользователей AgentFlow. Делитесь идеями, спрашивайте, общайтесь.` | Plain Russian, no «бесплатно», no jargon |
| `history_visibility` | `invited` | Members see history only from the moment they joined — keeps the timeline private to logged-in users, prevents anonymous archive crawls |
| `invite` (creator only) | `af-claude`, `af-research`, `af-image`, `af-spec` | Bot roster present from the start; bots' `/sync` runner auto-accepts. `af-helper` is the creator (already in). `af-tg-poster` stays out (DM-only by design). |

### Env

| Var | Default | Purpose |
|---|---|---|
| `MATRIX_LOBBY_ALIAS` | `#lobby` | Alias local-part with leading `#`. Set to `#general` etc. to relocate without redeploy |
| `MATRIX_LOBBY_ENABLED` | `1` | Master switch. `0` disables boot-time provisioning AND per-bounce `/join` (staging Dendrites that should not have a shared room) |

### Failure modes

| Symptom | Log signature for grep | Where to fix |
|---|---|---|
| Lobby never appears in sidebar | `[chat-onboard] lobby create failed` | `MATRIX_REGISTRATION_SHARED_SECRET` mismatched or af-helper bot row absent; restart `agentflow-agents` so `ensureAllBots` re-seeds |
| Bounce returns 200 but user not joined | `[element-sso] lobby join failed` with `lobby_join_failed_404` | Room not provisioned yet. Manual recovery: `curl https://matrix.agentflow.website/_matrix/client/v3/directory/room/%23lobby%3Aagentflow.website` — if 404, restart agentflow-agents to trigger `ensureLobbyRoomAtBoot` |
| Cold-start race creates duplicate rooms | `[chat-onboard] lobby create failed` with `M_ROOM_IN_USE` | Expected on concurrent boots; the re-resolve branch handles it. Only a problem if the retry GET also fails |
| User can read history they shouldn't | (no log) | `history_visibility` got set to `world_readable`. Verify state event: `kubectl -n franchise-factory exec dendrite -- ...` |
| Lobby provisioning runs every boot | `[chat-onboard] lobby alias resolve unexpected` with non-404 status | Dendrite returning 5xx on directory lookup — separate Dendrite issue |
| `MATRIX_LOBBY_ENABLED=0` but still joining | (no log) | Verify env was set on the deployment — `kubectl -n franchise-factory exec deploy/agentflow-agents -- env | grep MATRIX_LOBBY` |

## AgentFlow Space (Discord-style folder)

Element renders a `creation_content.type=m.space` room as a top-level sidebar icon. Clicking it pops out a panel with every child room — same UX shape as a Discord server.

### Files

| Path | Role |
|---|---|
| `src/services/bootstrap-channels.ts:bootstrapAgentflowSpace` | Boot-time entry point. Creates Space room, links children, invites all existing users. |
| `src/services/bootstrap-channels.ts:inviteUserToAgentflowSpace` | Per-user invite called from `/me/chat/element-sso` on first bounce. |
| `src/services/bootstrap-channels.ts:getAgentflowSpaceRoomId` | Cached room id helper; falls back to alias resolve. |
| `src/server.ts` | Calls `bootstrapAgentflowSpace` after `bootstrapPublicChannels` on the 60s delay. |
| `src/routes/element-sso.ts` | Invites the user to the Space after lobby join. |

### Children

| Alias | Role |
|---|---|
| `#agentflow-news` | release notes |
| `#agentflow-tutorials` | walkthroughs |
| `#agentflow-marketplace` | new agent listings |
| `#agentflow-bridges` | bridge status |
| `#agentflow-lobby` | общий чат — gets welcome message on first creation |
| `#agentflow-voice` | voice room (Element Call URL configured in `k8s/element-web-config.yaml`) |

### Wire shape

- Space room: `POST /_matrix/client/v3/createRoom` with `creation_content: { type: 'm.space' }`, `preset: public_chat`, `room_alias_name: agentflow-space`.
- Linking children: paired state events
  - On the Space: `m.space.child` `state_key=<child>` content `{ via: ['agentflow.website'], suggested: true }`.
  - On the child: `m.space.parent` `state_key=<space>` content `{ via: ['agentflow.website'], canonical: true }`.
- Auto-invite: at boot the af-helper bot invites every `users` row (cap 5 concurrent); on bounce the SSO route invites the freshly-provisioned user. Existing-member 403 is tolerated.

### Avatar

Skipped in v1. The Space renders with Element's default initial-letter avatar. TODO: ship a 256x256 PNG via `POST /_matrix/media/v3/upload` + a `m.room.avatar` state event once `@napi-rs/canvas` or a precomputed base64 buffer is in the build.

### Failure modes

| Symptom | Log signature for grep | Where to fix |
|---|---|---|
| Space icon missing from sidebar | `[bootstrap-channels] space createRoom failed` | af-helper bot row missing or Dendrite reachability — restart agentflow-agents |
| Child room shows in main sidebar instead of inside Space | `[bootstrap-channels] state event PUT failed` event_type=`m.space.child` | af-helper lost PL100 on the Space — re-create Space or grant PL |
| Child has no breadcrumb back to Space | `[bootstrap-channels] space.parent PUT failed` | Child was created by a different bot; m.space.parent half needs PL>=50 on the child |
| New user doesn't see Space until second bounce | `[element-sso] space invite failed` | bootstrapAgentflowSpace hasn't run yet on this pod restart — wait 60s |
| Voice room is just a normal chat | (no log) | Element Call not wired in `k8s/element-web-config.yaml`; v1 ships voice as a plain room |
