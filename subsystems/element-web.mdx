# Element Web

> **Status: Phase 1 + Phase 2 + Phase 3 shipped 2026-05-21.** Apache-2.0 image of `element-hq/element-web` deployed unbranded, then re-themed via `config.json`, then wired to AgentFlow SSO via a `/sso/element-sso` bounce that seeds Element's `localStorage` from the `af_session` cookie. No second login prompt.

## TL;DR

`vectorim/element-web:v1.12.18` deployed as a single-replica nginx-served SPA in `franchise-factory` namespace, behind ingress `chat.agentflow.website` with cert-manager LE-prod TLS. `config.json` is shipped via ConfigMap and pins `default_server_config.m.homeserver` to our Dendrite (`matrix.agentflow.website`, server name `agentflow.website`). `disable_custom_urls=true` and `disable_guests=true` keep users on our homeserver. Existing custom React `/chat` UI is untouched — switch-over happens in a later phase.

## Data flow

```
Browser → https://chat.agentflow.website
  │  GET /            → nginx serves SPA shell (index.html)
  │  GET /config.json → ConfigMap-mounted Element config (homeserver pinned)
  │
  └── Element JS boots, reads config.json, opens session against
      https://matrix.agentflow.website (Dendrite, federation OFF)
         │
         └── Phase 2: SSO via bridge endpoint /me/chat/token on agentflow-agents
             (deterministic-password shared-secret register/login).
             Currently users log in manually with username/password.
```

## DB / Env / API

- **Tables:** none (client-only, all state in Dendrite + browser IndexedDB).
- **Env (deployment):**
  - `ELEMENT_WEB_PORT=80` — **required override**. Without it k8s service-link auto-injection sets `ELEMENT_WEB_PORT=tcp://<svc-ip>:80` (because the Service name matches the deployment) and the upstream nginx template crashes with `invalid host in "tcp://..." of the "listen" directive`. We also set `enableServiceLinks: false` on the pod spec to belt-and-suspender this.
- **Routes:**
  - `GET https://chat.agentflow.website/` — Element SPA shell (200, `<title>Element</title>`).
  - `GET https://chat.agentflow.website/config.json` — runtime config (homeserver pin, branding hooks).
- **MCP tools:** none.
- **Upstream image:** `vectorim/element-web:v1.12.18` (Apache 2.0). Base layer `nginxinc/nginx-unprivileged:alpine-slim`, runs as uid 101.

## Phase 3: SSO bounce (shipped 2026-05-21)

Element does not run any auth UI in our deployment. Users who are already logged into AgentFlow click "Open chat" → end up in Element's room list without typing anything.

### Data flow

```
Browser (signed into AgentFlow)
   │  click "Open chat" → https://chat.agentflow.website/sso/element-sso
   ▼
nginx-ingress (chat.agentflow.website)
   │  use-regex + rewrite-target: /sso/(.*) → /me/chat/$1
   │  upstream: agentflow-agents.franchise-factory.svc:4100
   ▼
agentflow-agents  GET /me/chat/element-sso
   │  requireSession reads af_session cookie (Domain=.agentflow.website)
   │  issueMatrixTokenForAfUser(af_id)
   │  → { user_id, access_token, device_id, homeserver }
   │  buildElementSeedHtml(...) → text/html
   ▼
Browser executes inline <script>
   │  localStorage.setItem('mx_user_id',      '@user-N:agentflow.website')
   │  localStorage.setItem('mx_access_token', 'syt_...')
   │  localStorage.setItem('mx_hs_url',       'https://matrix.agentflow.website')
   │  localStorage.setItem('mx_device_id',    '...')
   │  localStorage.setItem('mx_is_guest',     'false')
   │  location.replace('/')
   ▼
Element Web /  →  restoreSessionFromStorage  →  /sync  →  room list
```

### Why the endpoint runs on the chat host

`localStorage` is partitioned per origin. Setting the keys from `agents.agentflow.website` would land in the wrong storage partition and Element would boot unauthenticated. The `element-web-sso` Ingress reverse-proxies the call through `chat.agentflow.website` so the seed page returns from the same origin Element runs on.

### Env additions

| Var | Value (prod) | Purpose |
|---|---|---|
| `SESSION_COOKIE_DOMAIN` | `.agentflow.website` | `af_session` cookie scope; must include `chat.` subdomain |

### Security

- The bounce HTML carries a real Matrix access_token in the body. `Cache-Control: no-store` + `Referrer-Policy: no-referrer` + CSP `default-src 'none'; script-src 'unsafe-inline'` prevent caches / extensions from harvesting it.
- The seed JSON is `JSON.stringify`'d with `<` → `<` so a `</script>` substring in any field cannot break out of the bootstrap script block.
- Redirect target whitelist `/^\/[A-Za-z0-9_\-./?&=#]*$/` collapses anything else to `/` so a future `?next=` param cannot turn this into an open redirect / XSS sink.
- Cookie remains `HttpOnly Secure SameSite=Lax|None`. The seed page reads localStorage but not the cookie.

## Failure modes

| Symptom | Log signature for grep | Where to fix |
|---|---|---|
| Pod CrashLoopBackOff on first start | `invalid host in "tcp://` in nginx logs | `k8s/element-web.yaml` — keep `enableServiceLinks: false` + `ELEMENT_WEB_PORT=80` |
| Pod stuck `CreateContainerConfigError` | `container has runAsNonRoot and image has non-numeric user (nginx)` | `k8s/element-web.yaml` — keep `runAsUser: 101, runAsGroup: 101` in `securityContext` |
| Cert never issues | `Issuing` status on `certificate/element-web-tls`, ACME HTTP-01 challenge ingress present long-term | Verify `chat.agentflow.website` A-record points at 144.217.65.94 and nginx-ingress is reachable on :80 |
| Element loads but homeserver dropdown asks for URL | `default_server_config` missing | Edit ConfigMap `element-web-config`, `kubectl rollout restart deploy/element-web` |
| Login screen lets users type any homeserver | `disable_custom_urls` flipped to false | Same ConfigMap |
| Login fails with `M_FORBIDDEN` | n/a (Dendrite-side) | Check `dendrite` pod logs, registration shared-secret + appservice config |
| Theme reverts to upstream dark | `default_theme: "dark"` in ConfigMap | Restore `default_theme: "custom-AgentFlow Dark"` and verify `setting_defaults.custom_themes[].name == "AgentFlow Dark"` (Element prepends `custom-` automatically) |
| Auth screen shows Element logo | `branding.auth_header_logo_url` empty or pointing at `logos/element-logo.svg` | Set to `https://agentflow.website/favicon.svg` |
| "Get Element on iOS" banner appears | `mobile_guide_toast` true or `mobile_builds` missing | Set `mobile_guide_toast: false`, `mobile_builds: {ios:null, android:null, fdroid:null}` |
| SSO bounce returns 401 unauthenticated | `unauthenticated` from `requireSession` | Cookie `Domain=` missing — verify `SESSION_COOKIE_DOMAIN` env in `k8s/agentflow-agents.yaml` |
| SSO bounce returns 503 matrix_not_configured | `matrix_not_configured` in response body | One of `MATRIX_*` env vars missing — see `services/env.ts:166` |
| SSO bounce returns 502 matrix_bridge_unreachable | `[element-sso] token issue failed` | Dendrite pod down or `MATRIX_AUTH_KEY` rotated; check `kubectl logs deploy/dendrite` |
| Element shows login form after SSO redirect | no backend log — browser-side | localStorage write blocked (private mode / 3rd-party storage partition). Open chat in a top-level window, not iframe |
| Ingress 404 on `/sso/element-sso` | nginx-ingress 404 | `nginx.ingress.kubernetes.io/use-regex: "true"` missing on `element-web-sso` Ingress |
| SSO redirects user into wrong account | `restoreSessionFromStorage` succeeds with stale localStorage | Element didn't clear old session — user must Sign Out inside Element once, then re-hit `/sso/element-sso` |

## Operator runbook

**Update Element version:**
```
# Bump image tag in k8s/element-web.yaml, then:
scp k8s/element-web.yaml ff-france:/tmp/
ssh ff-france 'kubectl apply -f /tmp/element-web.yaml && kubectl -n franchise-factory rollout status deploy/element-web --timeout=2m'
```

**Edit runtime config without rebuild:**
```
kubectl -n franchise-factory edit configmap element-web-config
kubectl -n franchise-factory rollout restart deploy/element-web
```

**Smoke check from any shell:**
```
curl -sI https://chat.agentflow.website                # expect 200, text/html
curl -s  https://chat.agentflow.website/config.json    # expect JSON with our homeserver
```
