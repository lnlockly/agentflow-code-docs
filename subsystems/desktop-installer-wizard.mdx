# Windows installer wizard

## TL;DR
`installer/setup_gui.py` ships as `agentflow-desktop-setup.exe`. Since 2026-05-25 the user pastes ONE token (`af_install_…` / `af_live_…`); the wizard exchanges it for a device row via `POST /me/devices`, writes `auth.json`, registers a logon scheduled task, and launches the daemon + tray. Advanced fields stay hidden behind a collapsible toggle.

## Data flow

```
User → Cabinet
   ↓ POST /me/api-keys/install-token (agentflow-api)
   ← raw_api_key (af_live_*)
User pastes raw_api_key in wizard
   ↓ parse_token("af_live_*")
   ↓ mint_device_via_api → POST {api_base}/me/devices  (x-api-key: af_live_*)
   ← { id, enrollment_token }
write_auth_file({api_key, device_id, enrollment_token, device_secret=""})
install_daemon_binary → %LOCALAPPDATA%\AgentFlow\agentflow-desktop.exe
register_scheduled_task (LogonTrigger, schtasks /XML)
launch_daemon → WS connect with x-api-key + x-device-id + x-enrollment-token
   ← hello_ack {device_secret}   (one-time exchange; secret persists in auth.json)
```

## DB / Env / API
- Files: `%USERPROFILE%\.agentflow\auth.json` (api_key, device_id, enrollment_token, device_secret, ws_url).
- Env: `AF_API_BASE` (override REST base, default `https://agentflow.website/_agents`), `AF_WS_URL` (override daemon WS), `AF_SETUP_EXE_OVERRIDE` / `AF_TRAY_EXE_OVERRIDE` (CI hooks).
- Routes: `POST /me/devices` (agentflow-agents, `x-api-key` auth), `POST /me/api-keys/install-token` (agentflow-api).
- Scheduled task: `AgentFlowDesktop` at logon, points at `agentflow-desktop.exe --daemon`.
- Tray autostart: `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\AgentFlowTray`.

## Failure modes
| Symptom | Log signature for grep | Where to fix |
|---|---|---|
| Wizard rejects `af_live_*` paste | `Токен не принят кабинетом (401)` | `installer/setup_gui.py:232` — check key is current, not revoked. |
| Cabinet unreachable from corporate NAT | `Кабинет недоступен:` | `installer/setup_gui.py:236` — set `AF_API_BASE` to mirror. |
| Response missing `enrollment_token` | `В ответе кабинета нет device_id или enrollment_token` | `agentflow-agents/src/routes/me-devices.ts` — backend shape drift. |
| Update button no-op in dev mode | `Источник:` then `fail` | `installer/setup_gui.py:962` — git/pip not on PATH. |
| Frozen update sha256 mismatch | `auto-update: sha256 mismatch` | `agentflow-computer-mcp/src/.../auto_updater.py:357` — re-publish SHA256SUMS. |
