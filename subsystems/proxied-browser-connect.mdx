# Proxied cloud-browser connect (FE)

## TL;DR
For platforms whose connector needs an IP-bound residential-proxy login (kwork
first), the Пульт connect drawer offers «Войти через защищённый браузер». It
opens a remote view of a chromium running in the pod behind the account's
sticky residential proxy; the user logs into the real platform there, and on
success the backend captures cookies into the vault. The FE renders frames by
polling `screenshot_url` and forwards clicks/keystrokes to `input_url`. The
platform password is typed straight into the real login page — never stored by
AgentFlow.

## Data flow
```
ConnectDrawer (platform with needsProxiedBrowserLogin)
  └─ ProxiedBrowserFlow mount
       startBrowserLogin(platform) ── POST /me/integrations/:platform/browser-login/start
         → { session_id, stream:{ screenshot_url, input_url, status_url, poll_interval_ms } }
       loop every poll_interval_ms:
         GET  screenshot_url  → image_base64  → <img src=data:png;base64,…>
         GET  status_url      → { connected, hint? }
       user click on <img> → map (clientX-rect)/rect.width * naturalWidth → remote (x,y)
         POST input_url { action:'click', x, y }
       user types (canvas focus OR text-input affordance)
         POST input_url { action:'type', text } | { action:'press', key }
       status.connected:true → stop loop → cancelBrowserLogin → onConnected() (invalidate accounts)
  └─ unmount / «Отмена» → cancelBrowserLogin (best-effort)
```

## DB / Env / API
- Routes (agents service): `POST /me/integrations/:platform/browser-login/start`,
  `GET …/:session_id/screenshot`, `POST …/:session_id/input`,
  `GET …/:session_id/status`, `POST …/:session_id/cancel`. (#1114/#1115)
- Capability: `needsProxiedBrowserLogin` — FE registry today
  (`PROXIED_BROWSER_PLATFORMS = {kwork}`); swap to a live
  `GET /me/accounts/platforms` flag when the BE ships it.
- No new env / tables on the FE.

## Failure modes
| Symptom | Log signature for grep | Where to fix |
|---|---|---|
| Frames never appear, drawer shows shimmer | `Не удалось запустить браузер` | `ProxiedBrowserFlow.tsx` boot catch |
| Session torn down mid-login | `Сессия браузера завершилась` | poll-loop 4xx handler (`status >= 400 && status !== 429`) |
| Clicks land in the wrong spot | (no log) check `naturalWidth`/`naturalHeight` vs rendered `getBoundingClientRect` | `handleViewportClick` |
