# AI-Видео (brief → Remotion reel)

## TL;DR

`POST /me/functions/video { brief }` generates a short script via the flow LLM
router, renders one reusable Remotion composition (`brief-reel`, vertical
1080x1920) on the standalone `agentflow-remotion-runner` pod, and returns a
real MinIO MP4 URL. No new infra — it reuses the renderer, MinIO upload, and
designapi image path already documented in
[Remotion renderer](/subsystems/remotion-renderer).

## Data flow

```
POST /me/functions/video { brief }            (requireSession → session.sub)
   │
   ├─ brief? ──► generateVideoScript ──► invokeAI(ModelType.TEXT_LARGE)   [flow router]
   │                └─ extractJson → normalizeScript (clamp scenes/text/hex)
   │   script? ──► normalizeScript (skip LLM)
   │
   ├─ with_images? ──► attachSceneBackgrounds ──► generateImageSoftFail   [designapi, soft-fail]
   │
   └─ renderRemotion({ composition_id:'brief-reel', props })
            └─► POST http://agentflow-remotion-runner:4200/render
                  └─► selectComposition + renderMedia (chromium) → MinIO
            ◄── { ok, mp4_url, duration_sec, size_bytes, render_ms }
   ◄── { ok, mp4_url, duration_sec, width:1080, height:1920, script }
```

## DB / Env / API

- **Tables:** none. Stateless — render artifacts live in MinIO under
  `remotion/brief-reel/<uuid>.mp4`.
- **Env (agents pod):** `REMOTION_RUNNER_URL` (default
  `http://agentflow-remotion-runner:4200`). Empty → `renderRemotion` returns
  `remotion_runner_not_configured` (no HTTP attempted). LLM + image providers
  resolve through the flow router (no model name hardcoded).
- **Routes:**
  - `POST /me/functions/video` — body `{ brief?, script?, with_images?, fps? }`,
    requires `brief` OR `script`. Returns `{ ok, mp4_url, duration_sec,
    size_bytes, render_ms, composition_id:'brief-reel', width:1080,
    height:1920, script }`.
- **Composition props (`brief-reel`):**
  `{ title, subtitle?, scenes:[{heading, body?, bgImage?}], cta?, brand?,
  accentColor?, bgColor? }`. `bgImage` must be an absolute http(s) URL the
  render pod can fetch; a dead URL falls back to the branded gradient.

## Failure modes

| Symptom | Log / response signature for grep | Where to fix |
|---|---|---|
| Missing brief and script | `400 { error:"validation_error" }` | Caller — send `brief` or `script`. |
| LLM returned no JSON | `502 { error:"script_generation_failed" }`; `video_script_no_json` thrown | Model regression — inspect `generateVideoScript` reply; retry. |
| Empty LLM reply | `video_script_empty_llm_reply` | Flow router returned no text block — check provider health. |
| Runner pod down / Service unreachable | `503 { reason:"remotion_runner_unreachable" }` | `kubectl -n franchise-factory get pods -l app=agentflow-remotion-runner`. |
| Render >5 min | `503 { reason:"remotion_runner_timeout" }` | Shorten scenes; AbortSignal.timeout fires at 5 min. |
| Bad props / Chromium crash | `502 { reason:"render_failed" }` | Inspect `details`; usually a malformed prop or OOM. |
| Runner URL unset | `503 { reason:"remotion_runner_not_configured" }` (no HTTP) | Set `REMOTION_RUNNER_URL` on `deploy/agentflow-agents`. |
| Image provider down (with_images) | warn `scene background generation failed` — render continues on gradient | Expected soft-fail; no action. |
