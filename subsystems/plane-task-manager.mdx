# Plane Task Manager

## TL;DR
A self-hosted [Plane](https://plane.so) instance (open-source project/issue
tracker) runs on the cluster at `tasks.agentflow.website` and is the backend for
the [tasks MCP server](/subsystems/tasks-mcp). The k8s manifests under
`k8s/plane/` deploy postgres + redis + rabbitmq + minio + the Plane api / worker
/ beat / web / space / admin / live processes. `scripts/plane-bootstrap.sh`
seeds the admin user, the `AgentFlow` workspace, and a workspace API token, then
prints `PLANE_API_TOKEN` / `PLANE_WORKSPACE` to paste into the agents secret.

## Data flow
```
k8s/plane/*  → postgres + redis + rabbitmq + minio
             → plane-api (Django, :8000) ← worker / beat / live / web / space / admin
ingress tasks.agentflow.website → web/space/admin + /api → plane-api

scripts/plane-bootstrap.sh
   kubectl exec into a Running plane-api pod
   → create admin + AgentFlow workspace + workspace API token
   → prints PLANE_API_TOKEN= / PLANE_WORKSPACE=  → paste into agents secret
   → tasks MCP reads PLANE_API_BASE/TOKEN/WORKSPACE
```
REST shape (`plane-bootstrap.sh:177`): base `https://tasks.agentflow.website/api/v1/`,
header `X-API-Key: $PLANE_API_TOKEN`, `…/workspaces/$PLANE_WORKSPACE/projects/…`.

## DB / Env / API
- Env (consumed by tasks MCP): `PLANE_API_BASE` (e.g. `https://tasks.agentflow.website/api/`), `PLANE_API_TOKEN` (workspace API token, `X-API-Key`), `PLANE_WORKSPACE` (workspace slug).
- Env (live server): `API_BASE_URL` → `http://plane-api:8000` (in-cluster Service).
- Bootstrap env: `PLANE_ADMIN_EMAIL`, `PLANE_ADMIN_PASSWORD`, `PLANE_WORKSPACE_NAME` (default `AgentFlow`), `PLANE_WORKSPACE_SLUG` (default `agentflow`), `PLANE_TOKEN_LABEL` (default `agentflow-mcp`).
- Host: `tasks.agentflow.website`.

## Failure modes
| Symptom | Log signature for grep | Where to fix |
|---|---|---|
| `plane-live` CrashLoopBackOff at boot | `API_BASE_URL must be a valid URL` | declare `API_BASE_URL` in `agentflow-agents/k8s/plane/36-live.yaml:66` |
| bootstrap finds no api pod | `ERROR: no Running plane-api pod found in ns` | `agentflow-agents/scripts/plane-bootstrap.sh:67` |
| bootstrap printed nothing usable | grep guard fails on `^PLANE_API_TOKEN=`/`^PLANE_WORKSPACE=` | `agentflow-agents/scripts/plane-bootstrap.sh:171` |
| tasks MCP returns `tasks_not_configured` | env unset after bootstrap | re-run bootstrap, paste token into agents secret |
