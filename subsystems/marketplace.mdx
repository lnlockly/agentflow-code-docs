# Marketplace

## TL;DR

Public catalog with two tabs: **Agents** (19 published listings from
`agents_marketplace_listings` table) and **Templates** (68 static cards from
`agentflow-landing/src/data/templates.ts`). List view fetched from
`GET /_agents/marketplace?sort=hires|rating|recent[&q=&category=&capability=]`.
Detail pages from `GET /_agents/marketplace/:slug`. Auth-gated CTAs:
**Hire** (forks the preset into user's account, requires `useAuth().isAuthenticated`),
**Fork-into-project**, **Playground**. Templates are anon-readable; agent
hire is owner-only.

## Data flow

```
User → /marketplace
       ↓
       MarketplaceV2 mount → listMarketplace({q,sort}) → GET /_agents/marketplace
       ↓
       19 li.afm-row rendered (no price chip!)
       ↓
User clicks row → setSelectedAgent → in-page dialog OR
User direct-nav → /marketplace/<slug>
       ↓
       MarketplaceDetail mount → getMarketplaceListing(slug) → GET /_agents/marketplace/<slug>
       ↓
       README + pricing chip rendered
       ↓
User clicks "Нанять в проект →"
       ↓
       handleHire: useAuth().isAuthenticated?
         no  → /account?next=/marketplace/<slug>   (or /login?next=…)
         yes → forkAgent({source_slug}) → POST /_agents/me/agents/from-preset
              → navigate(`/account/agents/<new_slug>`)
```

## DB / Env / API

- Tables: `agents_marketplace_listings`, `agents` (forked copy), `agent_pricing` (joined for `price_per_message_micro_usd`, `price_per_run_micro_usd`).
- Routes:
  - `GET /_agents/marketplace?sort=hires|rating|recent&q=&category=&capability=` — public.
  - `GET /_agents/marketplace/:slug` — public, returns `listing` (full README, tools, secrets, examples).
  - `POST /_agents/me/agents/from-preset` — auth-gated, forks the preset for the calling user.
- Front routes:
  - `/marketplace` → `MarketplaceV2`.
  - `/marketplace/:slug` → `MarketplaceDetail`.
  - `/templates` → `Templates` (anon).
  - `/templates/:slug` → `TemplateDetail` (anon).
