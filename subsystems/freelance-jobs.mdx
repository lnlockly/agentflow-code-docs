# Freelance Jobs

## TL;DR
`/jobs` — простая доска заказов. Юзер постит (`title + brief + budget_coins`),
другой юзер жмёт «Взять», статус атомарно `open → in_progress`,
`@af-helper` создаёт Matrix-комнату между ними. Кнопка «✨ Помоги дописать»
прогоняет черновик через `useModel(ModelType.TEXT_LARGE)` и возвращает
структурированный бриф (Задача / Результат / Сроки / Бюджет / Требования).
Эскроу, торги, рейтинги — v0.2+.

## Data flow

```
User → /jobs
       ↓
       Jobs.tsx mount → listFreelanceOrders({status:'open'}) → GET /_agents/me/freelance/orders
       ↓
       Render cards
       ↓
Юзер заполняет форму
       ↓ optional: "✨ Помоги дописать"
       POST /_agents/me/freelance/brief-helper → refineBrief() → TEXT_LARGE
       ↓
Юзер жмёт "Опубликовать" → POST /_agents/me/freelance/orders → INSERT fl_orders → 201
       ↓
Другой юзер видит карточку → "Взять"
       ↓
       POST /_agents/me/freelance/orders/:id/take
       UPDATE fl_orders SET status='in_progress', taken_by, taken_at WHERE id=:id AND status='open' AND owner_id<>:taker
       (атомарно — race-condition безопасно: только один UPDATE вернёт строку)
       ↓
       createOrderRoom(...) → @af-helper POST /_matrix/client/v3/createRoom (invite=[owner, taker])
       ↓
       UPDATE fl_orders SET room_id=...
       ↓
       Response { ok:true, order, room_id }
       ↓
       Фронт: navigate('/chat#/room/' + room_id)
```

## DB / Env / API

- **Tables**: `fl_orders` — см. миграцию `2026-05-25a-freelance-jobs.sql`.
- **Env**: `FF_FREELANCE=1` — feature gate (без него все маршруты 404).
- **Routes** (все под `/_agents/me/freelance/*`):
  - `GET  /orders?status=&q=&limit=`
  - `GET  /orders/:id`
  - `POST /orders` (auth, body `{title,brief,budget_coins}`)
  - `POST /orders/:id/take` (auth)
  - `POST /brief-helper` (auth, body `{rough}`)
- **Front routes**: `/jobs` (anon-readable список, авторизация требуется только на «Опубликовать» и «Взять»).
- **LLM**: `useModel(ModelType.TEXT_LARGE)` через ai-router. Никаких hard-coded моделей.
- **Matrix**: `@af-helper` access token из `matrix_bots`. Бот должен быть запущен (`MATRIX_BOTS_ENABLED=1`), иначе room creation тихо фейлится и заказ всё равно переходит в `in_progress`.

## Failure modes

| Симптом | Log signature for grep | Где чинить |
|---|---|---|
| `/jobs` отдаёт 404 на API | `feature_disabled` в response body | `FF_FREELANCE` не выставлен — `kubectl -n franchise-factory set env deploy/agentflow-agents FF_FREELANCE=1`. |
| Заказ создаётся, но room_id всегда null | `[freelance-room] no af-helper bot identity — skip` или `create failed` | В `matrix_bots` нет строки `af-helper` ИЛИ `accessToken` пустой ИЛИ `MATRIX_HOMESERVER_INTERNAL` не задан. Поднять `matrix-bots` runner. |
| «Взять» сразу даёт 409 `already_taken` | `409` на `POST /me/freelance/orders/:id/take` | Race — кто-то опередил. UI делает `load()` в `finally`, список обновляется. |
| «Взять» даёт 409 `cannot_take_own` | `cannot_take_own` в response | Заказчик нажал на свой же заказ. UI должен скрывать кнопку для своих, но пока не скрывает — TODO в v0.2. |
| AI brief-helper возвращает исходный rough без изменений | `[me-freelance] brief-helper failed` в логах | LLM-вызов выкинул. Проверить ai-router health (`useModel TEXT_LARGE no_provider_registered`). На фронт уходит 502 → UI оставляет исходный текст. |
| `INSERT fl_orders` падает на CHECK title | 400 `bad_input` с `detail.fieldErrors.title` | Frontend zod ограничивает 3-200, бэк zod дублирует. Длиннее обрезается, короче — отказ. |

## Что НЕ в v0.1 (backlog v0.2)

- **Эскроу монет**: использовать `chat_game_balances` + паттерн `stake / awardPot` из `bot-platform/src/routes/games.ts`. Кнопка «Подтвердить выполнение» переводит coins owner → taker.
- **Торги/заявки** (`fl_bids`): сейчас «первый нажал — взял». Добавить таблицу заявок + выбор исполнителя.
- **Рейтинги** (`fl_reviews`): после `status=done` обе стороны ставят оценку.
- **Скрывать «Взять» для своих заказов** на фронте.
- **Push-уведомление** заказчику когда кто-то взял (через `@af-helper` DM).
