# AgentFlow Academy

## TL;DR

Academy — это полноценный учебный план по AgentFlow, организованный в шесть
тематических модулей. Каждый модуль ведёт от первого подключения устройства
до автономной работы агента на маркетплейсе, в kwork-кабинете или в TG. Курсы
живут в Postgres (`courses` → `course_modules` → `course_lessons`),
прогресс пользователя — в `course_enrollments`. Frontend по URL `/academy`
читает только REST из `agentflow-agents`.

Содержание прошито в коде через `seed-academy.ts` (idempotent upsert на старте
сервера). Меняешь текст урока — пушишь PR в agentflow-agents — на деплое
сидер UPDATE'ит существующую строку. Никаких ручных SQL.

## Curriculum map

Шесть модулей покрывают весь жизненный цикл пользователя AgentFlow.

| # | Модуль (slug) | Цель | Курсы (slug) |
|---|---|---|---|
| 1 | Старт (`start`) | Поставить устройство, понять платформу, поднять свои API-ключи | `start-ai-agent`, `platform-navigation-map`, `concierge-recommend-agent`, `device-and-integrations-quickstart`, `api-keys-and-llm-cabinet` |
| 2 | Маркетплейс и проекты (`marketplace`) | Найти готового агента, нанять, выбрать kind проекта, склонировать шаблон | `marketplace-browse-hire`, `image-poster`, `researcher-topic`, `shorts-from-images`, `project-kinds-walkthrough`, `templates-gallery-clone` |
| 3 | Kwork-автоматизации (`kwork`) | Подключить кабинет Kwork, поднять трио (auto-bidder + replier + service-creator) | `kwork-account-farm-graph` |
| 4 | Telegram (`telegram`) | Контакт-ферма, рассылка, прогрев | `farm-quickstart`, `tg-farm-broadcast-launch` |
| 5 | Соцсеть (`social`) | Проекты, новости, публичные ссылки на чат | `share-chat-snapshot`, `social-network-projects` |
| 6 | Заработок (`earnings`) | Пополнить USDT, купить тариф, вывести USDF, квесты + рефералы | `billing-topup-usdt`, `billing-buy-subscription`, `quests-referrals-earnings`, `withdraw-usdf-to-usdt` |

Каждый курс в Postgres `courses.module_slug` хранит slug модуля. Frontend
`/academy` группирует карточки по модулям через `GET /modules` + `GET /courses`.

Полный mapping модулей → курсов → уроков — в [curriculum-map](/academy/curriculum-map).

## Data flow

```
seed-academy.ts (boot-time)
  → upsertCourse → upsertModule → upsertLesson
  → SET published=true

GET /courses
  → list of CourseRow (id, slug, title, tier, priceUsdf, durationMinutes)

GET /courses/:slug
  → { course, modules: [{ id, title, lessons: [{ id, slug, title, type, freePreview }] }] }

GET /lessons/:id
  → { lesson: { contentJson, transcript, type, durationSeconds } }

POST /me/courses/:slug/enroll      (cookie-auth, idempotent)
POST /me/courses/:slug/lessons/:id/complete  (cookie-auth, upsert)
GET  /me/courses/:slug/progress    (cookie-auth, returns completed_at[])
```

## DB / Env / API

- Tables: `courses`, `course_modules`, `course_lessons`, `course_enrollments`
- Env (frontend): `VITE_AGENTS_URL` — base для академии (default `https://agents.agentflow.website`)
- Routes:
  - Public: `GET /courses`, `GET /courses/:slug`, `GET /lessons/:id`, `GET /modules` (iter2)
  - Cookie-auth: `POST /me/courses/:slug/enroll`, `POST /me/courses/:slug/lessons/:id/complete`, `GET /me/courses/:slug/progress`
- Frontend routes: `/academy`, `/academy/:slug`, `/academy/:slug/lesson/:id`
- Iter2 column: `courses.module_slug TEXT NOT NULL DEFAULT 'misc'` — добавлена через `bootstrap-schema.ts` (ADD COLUMN IF NOT EXISTS), сидер выставляет реальный slug при upsert.

## Video lessons (iter3, 2026-05-25)

Уроки типа `video` рендерятся плеером `<video>` в `AcademyLessonPlayerPage.tsx`
(`if (lesson.type === 'video')`). Источник — `contentJson.video_url`.

### Где хранится файл

`agentflow-landing/public/academy/lesson-videos/*.mp4` — статические assets,
отдаются landing nginx как `https://agentflow.website/academy/lesson-videos/<file>.mp4`.
Никакой backend-handler, никакого upload-flow.

### Формат

| Поле | Значение |
|---|---|
| Контейнер | MP4 (H.264 video + AAC silent audio) |
| Размер | 1280×720, 30fps |
| Длительность | 60-90 секунд |
| Bitrate | ~50-80 KB/s (~500 KB на 75 секунд) |
| Audio | Silent AAC track — иначе Telegram считает файл за GIF |

### Как добавить интро-видео в модуль

1. Сгенерируй mp4 по шаблону (см. `/tmp/academy-build/make_video.py` в истории
   PR `agentflow-agents#828` — Python + PIL + ffmpeg, концат N screenshot-кадров
   с подписями + title slide + outro slide).
2. Скопируй файл в `agentflow-landing/public/academy/lesson-videos/<name>.mp4`.
3. В `seed-academy.ts` вызови `introVideoLesson({ fileName, title, ... })`
   как первый элемент массива `lessons:` нужного модуля. Хелпер ставит
   `order: -1`, поэтому видео-урок встанет перед уже существующими лекциями.
4. PR landing + PR agents → деплой → seeder на старте UPSERT-ит новый урок.

## Как добавить новый курс

1. Открой `agentflow-agents/src/db/seed-academy.ts`.
2. Скопируй блок `const COURSE_FOO: CourseSeed = { ... }` рядом с похожим курсом.
3. Замени `slug`, `title`, `description`, заполни модули и уроки (минимум один модуль с одним уроком).
4. Добавь имя константы в массив `ALL_COURSES`.
5. Запусти `npm run typecheck` локально.
6. PR в agentflow-agents → merge → деплой → на старте `seedAcademyPilotCourse` сделает INSERT новой строки и UPDATE для существующих.
7. Обнови `subsystems/academy.mdx` (этот файл) — добавь курс в таблицу Files и в Curriculum map.

### Стиль текста уроков

Правило копирайтинга, установленное владельцем 2026-05-15:
простой русский, без жаргона. Запрещены слова: `оператор`, `протокол`, `саплай`,
`казна`, `стейкхолдер`, `ончейн`, `децентрализованный`. Пишем так, будто
объясняешь нормальному человеку, который никогда не слышал про крипту.

Дополнительно (общий правило проекта `agentflow/CLAUDE.md`):
запрещены `реально`, `просто` (как пустое слово), `буквально`, `именно` (как
filler), em-dash как divider, throat-clearing openers, антитезы вида
«Не X. Y.», англицизмы `workspace`/`runtime` (пиши `рабочее пространство` /
`облачный компьютер`).

## Failure modes

| Симптом | Log signature for grep | Where to fix |
|---|---|---|
| Курс не появляется на `/academy` после деплоя | `seed academy: skipped` или нет `seed academy: courses=N` в логах | `agentflow-agents/src/server.ts` — проверь вызов `seedAcademyPilotCourse()` |
| Курс попадает в секцию "Без модуля" | `module_slug = 'misc'` в БД | `seed-academy.ts` — у `CourseSeed` нет поля `moduleSlug` или указан несуществующий slug |
| `/academy` не группирует, рендерит одной кучей | `GET /modules` → 404 | старый backend без iter2 — фронт падает на `ACADEMY_MODULES_FALLBACK`, проверь деплой agentflow-agents |
| Урок открывается без контента | response `/lessons/:id` = `null` | `seed-academy.ts` — у урока пустой `contentJson` |
| `/me/courses/.../enroll` возвращает `null` | `[academy] enroll: no session` | пользователь не залогинен — фронт должен редиректить на `/login` |
| Прогресс не сохраняется | `[academy] mark-complete: lesson not in course` | `markComplete` шлёт `lessonId` из чужого курса — проверить `slug` параметр |
| Сидер падает на старте | `seed academy: failed` + `duplicate key` | Кто-то руками вставил курс с тем же `slug` — удалить и перезапустить |
