# Desktop-agent attach flow

## TL;DR

Юзер находит в `/marketplace` карточку агента с `kind=desktop_agent` (например `desktop-assistant`), жмёт **Attach to my Mac**, выбирает один из своих зарегистрированных Mac'ов (или сначала регистрирует через `/cabinet/devices`), и попадает в workspace проекта со live-view сессии. На стороне сервера: создаётся `projects` row с `kind=desktop_agent`, graph-executor выполняет единственный node `attach_computer_tools` — он проверяет что device online, создаёт `device_sessions` row, инжектит scope в runtime-контекст. Дальше Eliza-агент крутит цикл `screen.capture → reason → mouse/keyboard/...` пока не достигнет цели / max_actions / budget / юзер не нажмёт Revoke.

## DB / Env / API

**Tables touched (in order):**

- `user_devices` — read (SELECT for online check).
- `projects` — INSERT (`kind='desktop_agent'`, `status='approved'`).
- `project_agents` — INSERT (`project_id`, `agent_id`).
- `device_sessions` — INSERT (`device_id`, `agent_id`, `project_id`, `status='active'`).
- `device_action_log` — INSERT one row per tool call (immutable).
- `project_events` — INSERT (`kind: 'desktop_session_started'`, `desktop_session_ended'`).

**Routes:**

- `GET    /me/devices` — picker source.
- `POST   /me/projects` — body `{kind:'desktop_agent', agent_id, device_id, brief}`.
- `POST   /me/projects/:id/approve` — auto-fires for desktop_agent (no manual approve).
- `GET    /me/devices/:id/sessions/:sid/stream` — SSE.
- `POST   /me/devices/:id/sessions/:sid/abort` — manual revoke from workspace UI.

**Frontend routes:**

- `/marketplace/:slug` → "Attach to my Mac" → modal.
- `/account/projects/:id` — workspace, renders `<DeviceLiveSession />` when `kind=desktop_agent`.
- `/cabinet/devices/:id` — also shows the same session list, drilldown.

## Failure modes

| Symptom | Log signature for grep | Where to fix |
|---|---|---|
| "Attach to my Mac" 400 — no device picked | (frontend validation) | `AttachToMacDialog.tsx:(TBD)` requires `device_id` |
| 400 `device_offline` on approve | `[desktop_agent] device_offline device_id=` | `kinds/desktop-agent.ts:(TBD)` — tell user to start launchd job |
| 400 `device_not_owned` | `[desktop_agent] device_not_owned` | UI bug — frontend sent device_id belonging to another user |
| 403 `forbidden` on hire | `marketplace_hire forbidden caller=` | Project owner check — only owner can attach |
| Session created but live view stuck spinning | SSE 401 / CORS reject | `routes/me/devices.ts:(TBD)` — SSE auth header propagation |
| Agent loops forever, ignores task.complete | `device_session actions_used >= max_actions` | Preset bug — agent doesn't call task.complete; raise `max_actions` or fix preset |
| Cost spikes past `budget_usd` | `[device] budget exceeded session=` then session aborted | Working as designed — informs user, raise budget if needed |
| `screen.capture` returns empty / black image | `Screen Recording permission denied` in `~/Library/Logs/agentflow-computer-mcp.log` | macOS permission not granted; see [Device registration runbook](/runbooks/device-registration) |
