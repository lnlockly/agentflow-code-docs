# Cabinet navigation IA

## TL;DR

The authenticated cabinet nav leads with **4 core surfaces** — Проекты,
**Агенты** (`/cabinet/agents` hub, A2), Маркетплейс, **Баланс и AI**
(renamed from «LLM-кабинет», Фаза 1) — under an «Основное» group, with a
pinned «Главная» home above it. **Приложение** (desktop agent) and
**Облако** (24/7) moved out of core into «Ещё» in A2 — they remain the
device substrate the «Агенты» hub reads from, just no longer top-level.
Everything else (мои агенты, flows, device skills, the `/apps` launcher,
billing, settings) is tucked behind a collapsible «Ещё» disclosure that
defaults closed. **Referrals live in exactly one place — the avatar
dropdown** (de-duplicated in Фаза 1). All nav lives in one component;
`/apps` is the overflow launcher and the avatar dropdown carries
profile/referrals/settings/billing/logout.

The **«Агенты» hub** (`/cabinet/agents`) is two stacked sections: a static
catalog of 6 use-case scenarios (filter-chips by category, each card →
`/cabinet/agents/new?kind=<key>`) and «Твои агенты» — the user's running
agents, reusing the exact device data path from `CabinetDevices`
(`GET /me/devices` + `GET /me/hosted-devices`). `/cabinet/agents/new` is a
wizard placeholder (the create wizard + autoposting setup ship as a
separate follow-up).

## Data flow

```
AppShellV2 (every cabinet route)
  ├─ Главная            /cabinet                       (pinned, HOME_ITEM)
  ├─ «Основное» (CORE_NAV, always open — 4 items, A2)
  │   ├─ Проекты        /projects
  │   ├─ Агенты         /cabinet/agents  (hub: catalog + «Твои агенты»)
  │   ├─ Маркетплейс    /flows
  │   └─ Баланс и AI    /llm-cabinet     (renamed from «LLM-кабинет», Фаза 1)
  ├─ «Ещё» ▸ (MORE_NAV, collapsed by default, persisted)
  │   ├─ Приложение     /cabinet/devices              (moved from core, A2)
  │   ├─ Облако         /cabinet/devices/hosted/new   (moved from core, A2)
  │   ├─ Мои агенты     /account/agents   (key `my_agents` — distinct from core «Агенты»)
  │   ├─ Нанять агента  /marketplace
  │   ├─ Сценарии       /my/flows
  │   ├─ Навыки         /cabinet/devices/skills
  │   ├─ Приложения     /apps          ── overflow launcher (AppsLauncher)
  │   ├─ Биллинг        /account/usage   (also in avatar menu)
  │   └─ Настройки      /account/settings (also in avatar menu)
  ├─ «Десктоп-агент»   GitHub release download links
  └─ avatar dropdown   Profile · Рефералы · Settings · Billing · [Admin] · Logout
                       (referrals live ONLY here now — Фаза 1 de-dup)

/cabinet/agents (CabinetAgentsHub)
  ├─ Каталог: 6 UseCase cards + category filter chips → /cabinet/agents/new?kind=<key>
  └─ «Твои агенты»: GET /me/devices + GET /me/hosted-devices (same path as CabinetDevices)
/cabinet/agents/new (CabinetAgentNew) — «Мастер скоро» stub, CTA → /cabinet/devices/hosted/new

mobile bottom bar (BOTTOM_NAV, 5): Главная · Проекты · Агенты · Маркетплейс · Ещё(/apps)
admin: on /admin/* AND is_admin → ADMIN_NAV replaces the workspace groups
```

## DB / Env / API

- Tables: none (pure client IA).
- Env: none.
- Routes referenced (all `RequireAuth` + `AccessGate`): `/cabinet`,
  `/projects`, `/cabinet/agents`, `/cabinet/agents/new`, `/flows`,
  `/llm-cabinet`, `/cabinet/devices`, `/cabinet/devices/hosted/new`,
  `/account/agents`, `/marketplace`, `/my/flows`, `/cabinet/devices/skills`,
  `/apps`, `/account/{referrals,usage,settings}`.
- APIs (hub «Твои агенты»): `GET /me/devices`, `GET /me/hosted-devices`.
- localStorage: `agentflow.sidebar.more-open` (disclosure state).

## Failure modes

| Symptom | Log signature for grep | Where to fix |
|---|---|---|
| Core surface missing from sidebar | `CORE_NAV` (grep the array) | `AppShellV2.tsx:110` — add the `NavItem` |
| «Ещё» won't expand | `af-sb__section-toggle` | `AppShellV2.tsx` toggle button + `dark-tokens.css:149` |
| Nav label shows raw key (`app.shell.nav.x`) | missing i18n key | add to all three of `src/i18n/{ru,en,zh}.json` |
| Cut feature reappears in nav (souls / квесты / singularity) | `souls` / `quests` / `Singularity` in a NAV array | keep them out of `CORE_NAV`/`MORE_NAV` (removed in landing #545/#547) |
| `/cabinet/agents` redirects to `/account/agents` instead of the hub | duplicate `<Route path="/cabinet/agents" …Navigate…>` | remove the stale redirect in `main.tsx` — the hub route must be the only one |
| Core «Агенты» and «Мои агенты» both show «Агенты» | both NavItems use key `agents` | core uses `agents`, MORE_NAV uses `my_agents` — keep the keys distinct |
| Hub tap targets render at 36px on mobile | `.af-shell-v2 button { min-height: 36px }` floor wins | `cabinet-agents.css` uses `min-height: 44px !important` on chips/refresh |
