# Cabinet navigation IA

## TL;DR

**UX-strip 2026-05-31** (owner «убрать лишнее, убирать лишний выбор»): the nav
now leads with **«Агенты»** as the **hero** (`/cabinet/agents`, accent-styled
even when not active) — the cabinet's primary story is the user's always-on
cloud pod (the engine: cron + content-gen + posting, all in-pod). Core is
3 items: **Агенты (hero) · Проекты (secondary) · Баланс и AI**. **«Маркетплейс»
(`/flows`) is hidden from the cabinet UI entirely** (activepieces going
optional/pro-only; route still resolves by direct URL). **`/apps` AppsLauncher
is removed** (owner «непонятная страница приложений») — route redirects to
`/cabinet`; the mobile 5th tab now opens the nav drawer instead of a dead
launcher. «Ещё» holds a single row — **Приложение** (`/cabinet/devices`, the raw
device list). Referrals/billing/settings live in the avatar dropdown.

The **«Агенты» hub** (`/cabinet/agents`) is two stacked sections: a static
catalog of 6 use-case scenarios (filter-chips by category, each card →
`/cabinet/agents/new?kind=<key>`) and «Твои агенты» — the user's running
agents, reusing the exact device data path from `CabinetDevices`
(`GET /me/devices` + `GET /me/hosted-devices`). `/cabinet/agents/new` is a
real 3-step scenario setup wizard (A2b — replaced the «Мастер скоро» stub):
**1. Что будет делать** (scenario pre-selected from `?kind`, brief textarea),
**2. Где + как часто** (cloud 24/7 recommended / Mac local + schedule chip),
**3. Контроль** (approval toggle + daily spend cap). Launch is real: cloud
posts `/me/hosted-devices` (daemon) + applies the control step as a
`DeviceScope` via `devicesApi.updateScope`, then navigates to the live device
page carrying the brief as `?task=`; a 404 degrades to a hand-off to the full
cloud wizard. Mac hands off to the local installer at `/cabinet/devices/new`.

## Data flow

```
AppShellV2 (every cabinet route)            ── UX-strip 2026-05-31
  ├─ Главная            /cabinet                       (pinned, HOME_ITEM)
  ├─ «Основное» (CORE_NAV, always open — 3 items)
  │   ├─ ● Агенты       /cabinet/agents  (HERO/accent — hub: catalog + «Твои агенты»)
  │   ├─ Проекты        /projects        (secondary, de-emphasised)
  │   └─ Баланс и AI    /llm-cabinet
  │   (Маркетплейс /flows REMOVED from UI — route resolves by direct URL only)
  ├─ «Ещё» ▸ (MORE_NAV, collapsed by default, persisted)
  │   └─ Приложение     /cabinet/devices              (raw device list)
  │   (/apps, Облако, Мои агенты, Нанять, Сценарии, Навыки — all pulled)
  ├─ «Скачать приложение» /download
  └─ avatar dropdown   Profile · Рефералы · Settings · Billing · [Admin] · Logout

create flow (one path, no choice — CabinetDeviceSetup at /cabinet/devices/new):
  step1 [Включить облако]  (one button, 0 pickers)  + «скачать приложение» → /download
  step2 auto-provision (size=medium, kind=daemon, template=coder — all defaulted)
  step3 первая задача (cloud outcome gallery, skippable)
  step4 готово → /cabinet/devices/hosted/<id>/live
  (/cabinet/devices/hosted/new + /cabinet/devices/new/cards redirect here)

/cabinet/agents (CabinetAgentsHub)
  ├─ Каталог: 6 UseCase cards + category filter chips → /cabinet/agents/new?kind=<key>
  └─ «Твои агенты»: GET /me/devices + GET /me/hosted-devices (same path as CabinetDevices)
/cabinet/agents/new (CabinetAgentNew) — 3-step scenario wizard
  ├─ 1. Что будет делать  (scenario from ?kind + brief textarea)
  ├─ 2. Где + как часто    (cloud daemon / Mac local + schedule chip)
  ├─ 3. Контроль          (approval → confirm_before, cap → budget_usd)
  └─ Запустить → cloud: POST /me/hosted-devices + updateScope → /cabinet/devices/hosted/<id>?task=
                 (404 → hand-off /cabinet/devices/hosted/new) · Mac → /cabinet/devices/new

mobile bottom bar (5): Главная · Агенты · Проекты · Баланс и AI · Ещё(→drawer)
admin: on /admin/* AND is_admin → ADMIN_NAV replaces the workspace groups
```

## DB / Env / API

- Tables: none (pure client IA).
- Env: none.
- Routes referenced (all `RequireAuth` + `AccessGate`): `/cabinet`,
  `/projects`, `/cabinet/agents`, `/cabinet/agents/new`, `/flows`,
  `/llm-cabinet`, `/cabinet/devices`, `/cabinet/devices/hosted/new`,
  `/account/agents`, `/marketplace`, `/my/flows`, `/cabinet/devices/skills`,
  `/apps`, `/account/{referrals,usage,settings}`.
- APIs (hub «Твои агенты»): `GET /me/devices`, `GET /me/hosted-devices`.
- localStorage: `agentflow.sidebar.more-open` (disclosure state).

## History

- **UX-strip** (2026-05-31, landing `feat/ux-strip`) — owner «убрать лишнее,
  убирать лишний выбор». `/apps` AppsLauncher removed (→ redirect `/cabinet`,
  pulled from sidebar + mobile nav). Device-create collapsed: the 4-card
  chooser (`CabinetDeviceNew`) and the 5-step kind/size/engine/perms wizard
  (`CabinetHostedDeviceNew`) both redirect to one no-choice `CabinetDeviceSetup`
  («Включить облако» + `/download`); size/engine/kind pickers killed (defaults
  in code: `medium`/`daemon`/`coder`). Scenario wizard (`CabinetAgentNew`) lost
  its cloud/local runtime choice — always the cloud pod. Sidebar: «Маркетплейс»
  (`/flows`) hidden entirely; «Агенты» is the hero (accent), «Проекты»
  secondary. New `hero` flag on `NavItem` + `.af-sb__nav-item.is-hero` CSS.
  `tsc -b` + `npm run build` green.
- **A2b scenario wizard** (2026-05-31, landing PR #571) — replaced the
  `/cabinet/agents/new` «Мастер скоро» stub with a real 3-step setup
  (что будет делать → где + как часто → контроль). Cloud launch creates a
  daemon via `/me/hosted-devices` + applies the control step as a
  `DeviceScope` (`updateScope`), then navigates to the live device with the
  brief as `?task=`; 404 hands off to the full cloud wizard, Mac hands off to
  `/cabinet/devices/new`. Catalog extracted to `lib/agentScenarios.ts`
  (shared by hub + wizard). Mobile-first verified at 390/360px.
- landing #545/#547 — first declutter pass: removed Singularity / Души /
  Квесты / legacy marketplace dupe; regrouped into four outcome groups.
- Category H `h-nav-declutter` (2026-05-30) — collapsed the four groups into
  «Основное» (the core 5) + a single collapsible «Ещё», promoted the
  previously hidden `/llm-cabinet` into the primary nav, surfaced Cloud as a
  distinct entry. Map: `plans/autonomous/_cat-h-ia-map.md`.
- Cabinet redesign **Фаза 1** (2026-05-30, landing PR #558) — renamed
  «LLM-кабинет» → «Баланс и AI» (`app.shell.nav.llm_cabinet`, `apps.tile.llm_cabinet`,
  `CabinetTopNav` subtitle, `LlmCabinet` document.title); removed the duplicate
  «Рефералы» tab from `LlmCabinetShell` and the `MORE_NAV` row, leaving referrals
  only in the avatar dropdown (`app.shell.menu.referrals`); decluttered the
  `/cabinet` home (quick actions 9→4, stat tiles 4→2, referrals widget dropped).
  Concept: `agentflow/CABINET-CONCEPT.html`.
- **A2 «Агенты» hub** (2026-05-30, landing PR #564) — new `/cabinet/agents`
  hub (scenario catalog + «Твои агенты», reusing the device queries) plus a
  `/cabinet/agents/new` wizard placeholder. `CORE_NAV` cut to 4 (Проекты,
  Агенты, Маркетплейс, Баланс и AI); «Приложение» + «Облако» moved into «Ещё»;
  the mobile bottom-bar «Приложение» tab became «Агенты». New i18n
