# Cabinet navigation IA

## TL;DR

The authenticated cabinet nav leads with the 5 surfaces the owner named as
core — Проекты, Приложение (desktop agent), Облако (24/7), **Баланс и AI**
(renamed from «LLM-кабинет», Фаза 1), Маркетплейс — under an «Основное»
group, with a pinned «Главная» home above it. Everything else (agents,
flows, device skills, the `/apps` launcher, billing, settings) is tucked
behind a collapsible «Ещё» disclosure that defaults closed. **Referrals
were de-duplicated in Фаза 1: removed from «Ещё» and from the LLM-cabinet
tab; they now live in exactly one place — the avatar dropdown.** All nav
lives in one component; `/apps` is the overflow launcher and the avatar
dropdown carries profile/referrals/settings/billing/logout.

## Data flow

```
AppShellV2 (every cabinet route)
  ├─ Главная            /cabinet                       (pinned, HOME_ITEM)
  ├─ «Основное» (CORE_NAV, always open)
  │   ├─ Проекты        /projects
  │   ├─ Приложение     /cabinet/devices
  │   ├─ Облако         /cabinet/devices/hosted/new
  │   ├─ Баланс и AI    /llm-cabinet     (renamed from «LLM-кабинет», Фаза 1)
  │   └─ Маркетплейс    /marketplace
  ├─ «Ещё» ▸ (MORE_NAV, collapsed by default, persisted)
  │   ├─ Мои агенты     /account/agents
  │   ├─ Сценарии       /my/flows
  │   ├─ Навыки         /cabinet/devices/skills
  │   ├─ Приложения     /apps          ── overflow launcher (AppsLauncher)
  │   ├─ Биллинг        /account/usage   (also in avatar menu)
  │   └─ Настройки      /account/settings (also in avatar menu)
  ├─ «Десктоп-агент»   GitHub release download links
  └─ avatar dropdown   Profile · Рефералы · Settings · Billing · [Admin] · Logout
                       (referrals live ONLY here now — Фаза 1 de-dup)

mobile bottom bar (BOTTOM_NAV, 5): Главная · Проекты · Приложение · Маркетплейс · Ещё(/apps)
admin: on /admin/* AND is_admin → ADMIN_NAV replaces the workspace groups
```

## DB / Env / API

- Tables: none (pure client IA).
- Env: none.
- Routes referenced (all `RequireAuth`): `/cabinet`, `/projects`,
  `/cabinet/devices`, `/cabinet/devices/hosted/new`, `/llm-cabinet`,
  `/marketplace`, `/account/agents`, `/my/flows`,
  `/cabinet/devices/skills`, `/apps`, `/account/{referrals,usage,settings}`.
- localStorage: `agentflow.sidebar.more-open` (disclosure state).

## Failure modes

| Symptom | Log signature for grep | Where to fix |
|---|---|---|
| Core surface missing from sidebar | `CORE_NAV` (grep the array) | `AppShellV2.tsx:110` — add the `NavItem` |
| «Ещё» won't expand | `af-sb__section-toggle` | `AppShellV2.tsx` toggle button + `dark-tokens.css:149` |
| Nav label shows raw key (`app.shell.nav.x`) | missing i18n key | add to all three of `src/i18n/{ru,en,zh}.json` |
| Cut feature reappears in nav (souls / квесты / singularity) | `souls` / `quests` / `Singularity` in a NAV array | keep them out of `CORE_NAV`/`MORE_NAV` (removed in landing #545/#547) |
