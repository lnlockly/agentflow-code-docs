# LLM Cabinet — frontend

## TL;DR

`/llm-cabinet` is the standalone cabinet shipped in `agentflow-landing`.
Five tabs: Кабинет (dashboard with balance + usage tiles), История (per-request
log), API (key CRUD + curl examples), Модели (catalog driven by
`/llm/v1/models`), Инструкции (4 quickstart recipes). The Models and Curl
tabs read live from the public LLM facade so the UI never drifts from the
actually-enabled provider set.

## Data flow

```
LlmCabinetShell (tab router via ?tab=)
  ├─ Кабинет     ──► apiGet /me/billing/usage?range=7d
  ├─ История    ──► apiGet /me/api-keys          (pick most-recent by last_used_at)
  │                └─► apiGet /me/api-keys/:id/recent?limit=100
  ├─ API        ──► apiGet /me/api-keys          (list)
  │                ├─ apiPost /me/api-keys       (create, raw key returned once)
  │                └─ apiDelete /me/api-keys/:id (revoke)
  ├─ Модели     ──► fetch https://agentflow.website/llm/v1/models  (public, no auth)
  └─ Инструкции ──► apiGet /me/api-keys          (first prefix for snippet)
```

`apiGet(path)` routes:

- `path` starts with `http*` → passed to `fetch` as-is (used for `/llm/v1/models`).
- otherwise → `${VITE_API_URL}${path}` (in prod: `/_api/me/api-keys/...`).

## DB / Env / API

- Frontend env:
  - `VITE_API_URL` — agentflow-api base (prod: `/_api`).
  - `VITE_AGENTS_URL` — agentflow-agents base (prod: `/_agents`).
- Backend routes consumed:
  - `GET /me/api-keys` — list keys (returns `{id, name, prefix, created_at, last_used_at, tier?, rate_limit_rpm?}`).
  - `POST /me/api-keys` — create, body `{name}`, returns `{ok, key, row}` (raw key shown once).
  - `POST /me/api-keys/install-token` — mint a key labelled `desktop-install-<YYYY-MM-DD-HH:MM>`; returns `{ok, id, name, prefix, raw_api_key, created_at}` with HTTP 201. Used by the "Установи AgentFlow Desktop" cabinet card to inline the key into the curl/PowerShell one-liner. Source: `agentflow-api/src/routes/api-keys.ts:99` (route) and `agentflow-landing/src/lib/devicesApi.ts:241` (caller).
  - `DELETE /me/api-keys/:id` — revoke.
  - `GET /me/api-keys/:id/recent?limit=100` — per-request log; rows `{id, endpoint, status_code, flow_charged, tokens_in, tokens_out, model, duration_ms, created_at}`.
  - `GET /me/api-keys/:id/usage` — aggregated `{by_endpoint, by_model, totals}` (not yet rendered in cabinet, used by `/account/usage`).
  - `GET /me/billing/usage?range=7d` — dashboard tiles (`total_spent_usd, total_requests, total_tokens`).
  - `GET https://agentflow.website/llm/v1/models` — public catalog, returns `{object, data:[{id, owned_by, agentflow_format, pricing?, context_window?}]}`.
- Backing tables (host service): `api_keys`, `api_key_usage`, `flow_balances`, `flow_ledger`, `flow_model_pricing`, `llm_provider_configs`. See [Public LLM Facade](/subsystems/public-llm-facade).

### Catalog visual fallbacks

`fetchEnabledModels()` consumes the live response. Visual fields
(`glyph / glyphBg / glyphText / tier`) are NOT in the API payload — they
come from `VISUAL_MAP` keyed by regex on `model.id` (claude-opus, gpt-5.5,
gemini, deepseek, …). Unknown models fall through to `FALLBACK_VISUAL`
(monochrome dot glyph).

Pricing strings appear only when `pricing.input` and `pricing.output` are
present. Without them the cabinet shows `уточняется` so the catalog can
display a new model the second it lands in `llm_provider_configs`,
before pricing is seeded.

## Failure modes

| Symptom | Log signature for grep | Where to fix |
|---|---|---|
| Models tab stuck on skeleton | `Каталог временно недоступен (...)` in DOM | `/llm/v1/models` 5xx — check `public-llm.ts` route + `loadConfigs` |
| Curl example 404s | `curl https://agentflow.website/v1/chat/completions` (without `/llm` prefix) | the path was missing `/llm/` before this PR — fixed at `ApiTab.tsx:239` |
| History tab empty for an active key | `apiGet('/me/api-keys/:id/recent?limit=100')` returns `{rows: []}` | confirm `api_key_usage` writes; see [Public LLM Facade § stream usage capture](/subsystems/public-llm-facade) |
| Model dropdown only shows static 4 | `fetchEnabledModels()` threw, fell back to `MODELS` static array | check network for `/llm/v1/models` 5xx; static array kept as last-resort |
| Status column always green even on 4xx | `statusColor(code)` not matching | `HistoryTab.tsx:76` — only treats 2xx as `var(--lc-acid)`; verify `r.status_code` is numeric in row |
