# Public LLM Facade

## TL;DR

`/llm/v1/*` exposes one OpenAI-compatible and one Anthropic-compatible
endpoint for `af_live_*` API key holders. Routes pick the upstream provider
(codex.sale / east-api-3) from `llm_provider_configs`, proxy the request,
record token usage in `api_key_usage`, and debit `flow_balances` via
`chargeLlmUsage`. Streaming OpenAI requests opt the upstream into
`stream_options.include_usage` so the final chunk carries token counts.

## Data flow

```
client SDK
  │ Authorization: Bearer af_live_…
  ▼
authGate ─ validateApiKey() ── api_keys WHERE key_hash = HMAC(raw)
  │
  ▼
pickUpstreamForModel(model) ── llm_provider_configs WHERE enabled=true
  │
  ▼
proxyOpenAi / proxyAnthropic
  ├─ stream=true  →  callUpstream() → teeSseWithObserver()
  │                                     │
  │                                     │  OpenAI: usage in final empty-choices chunk
  │                                     │          (require stream_options.include_usage=true)
  │                                     │  Anthropic: message_start.usage + message_delta.usage
  │                                     ▼
  │                              recordUsage({ tokensIn, tokensOut, ... })
  │                                     │
  └─ stream=false → JSON parse → recordUsage()
                                        │
                                        ▼
                       chargeLlmUsage(model=normalizeClaudeModelId(model))
                       │   ├─ flow_model_pricing lookup
                       │   ├─ flow_balances debit (FOR UPDATE, gated)
                       │   └─ flow_ledger insert
                       └─ api_key_usage insert (tokens_in, tokens_out, flow_charged, model raw)
```

## DB / Env / API

- Tables: `api_keys`, `api_key_usage`, `llm_provider_configs`, `flow_model_pricing`, `flow_balances`, `flow_ledger`
- Routes:
  - `GET /llm/v1/health` — no auth
  - `GET /llm/v1/models` — no auth, returns `{ id, object, owned_by, agentflow_format, pricing, context_window }`
  - `POST /llm/v1/chat/completions` — OpenAI wire
  - `POST /llm/v1/messages` — Anthropic wire
  - `GET /llm/install.sh?key=…` — shell installer that writes env block to `~/.zshrc`/`~/.bashrc`
- Auth header: `x-api-key: af_live_*` OR `Authorization: Bearer af_live_*`
- Env:
  - `API_KEY_HMAC_SECRET` (or fallback `AUTH_JWT_SECRET + ':apikeys'`)
  - `ANTHROPIC_API_VERSION` (default `2023-06-01`)
  - per-row `api_key_env` from `llm_provider_configs` (eg. `CODEX_SALE_API_KEY`, `EAST_API_3_KEY`)

### `pricing` field shape (in `/llm/v1/models`)

```json
{
  "input_per_mtok": 2.5,
  "output_per_mtok": 10.0,
  "currency": "usd"
}
```

`pricing: null` when no active row in `flow_model_pricing` matches the model id. `context_window: null` when the model is not in the hardcoded map (add it in `MODEL_CONTEXT_WINDOWS`).

### Model id dot/dash normalization

Upstreams return Claude model ids in dot form (`claude-haiku-4.5`), but `flow_model_pricing.model_id` is seeded in dash form (`claude-haiku-4-5`). `normalizeClaudeModelId(model)` replaces `.` with `-` for any model starting with `claude-`. Non-claude models pass through unchanged. The `api_key_usage.model` column still records the raw upstream string so operators can grep for drift; `chargeLlmUsage(model:)` receives the normalized form.

## Failure modes

| Symptom | Log signature for grep | Where to fix |
|---|---|---|
| Streaming OpenAI request charges 0 USDF | `api_key_usage` row has `tokens_in=0, tokens_out=0, flow_charged=0` for non-error 200 | check `stream_options.include_usage` injection in `routes/public-llm.ts:proxyOpenAi`; the upstream must support it |
| Pricing missing for new Claude model | `[public-llm-billing] chargeLlmUsage failed` or `flow_charged=0` for non-zero tokens | add row to `flow_model_pricing` keyed by DASH form (`claude-<…>-4-5`); `normalizeClaudeModelId` handles the dot→dash mapping for free |
| `/llm/v1/models` returns 500 | `catalog_unavailable` in response body | `loadConfigs` query failed — check `llm_provider_configs` row schema, DB connectivity |
| `pricing: null` in catalog for a real model | absent `flow_model_pricing` row with `active=true AND model_id=<dash-form>` | seed the pricing row |
| New model has `context_window: null` | absent key in `MODEL_CONTEXT_WINDOWS` | add to `services/public-llm-upstream.ts:MODEL_CONTEXT_WINDOWS` |
| Invalid key returns 401 even after creation | HMAC secret mismatch | confirm `API_KEY_HMAC_SECRET` matches the secret used at key-create time |
| Spend cap blocks user | `Spend cap reached: $X of $Y this period.` 402 response | raise `api_keys.spend_limit_flow` or wait for period reset |
