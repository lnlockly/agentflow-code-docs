# AgentFlow Code Map

This is the internal code-level documentation. **Not for end users** — public product docs live at [docs.agentflow.website](https://docs.agentflow.website).

## What lives here

- **Architecture overview** — 5 minute tour of the whole platform
- **Products** — visitka, bot pool, ferma, channel variants, tg templates, graph executor
- **Subsystems** — 12 pages covering code-exec MCP, pod pre-warm pool, Caddy preview, runtime supervisor, LLM router, TG MCP, auth, projects frontend, graph handlers, feature flags, brief-fidelity supervisor, deploy shield
- **Flows** — step-by-step paths through the system (with file refs)
- **Runbooks** — debug stuck projects, add a kind, ship a boilerplate, canonical templates, scaffold hardening, update the RAG

## Conventions in this doc set

- Every file ref is in the form `repo/path/to/file.ts:lineNumber` so it pastes straight into `Read` or `Grep`.
- Failure modes section lists exact log strings to grep for.
- "Related" footer at the bottom of each page links to neighbours.
